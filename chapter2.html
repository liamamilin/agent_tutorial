1  智能体简史

Note上一章回顾

在第 1 章中，我们认识了智能体的基本概念，并用 30 行 Python 构建了第一个能对话的 SimpleAgent。但这个最简 Agent 只能”说”不能”做”——它没有任何工具，也没有推理能力。在为其添加这些能力之前，我们先回溯智能体的发展历史，理解当前的 LLM 智能体从何而来、为何是现在这个形态。

1.1 基于符号与逻辑的早期智能体

人工智能的早期研究深受数理逻辑与计算机科学基础理论的影响。研究者普遍认为，人类智能——尤其是逻辑推理能力——可以通过形式化的符号体系加以刻画和实现。这一理念催生了人工智能的首个重要范式——符号主义（Symbolicism），亦称”逻辑 AI”或”传统 AI”。

在符号主义框架下，智能被视为对符号依据明确规则进行操作的过程。智能体被建模为物理符号系统：利用内部符号表示外部世界，并通过逻辑推理来规划和决策。此类智能体的能力完全来源于设计者预先编写的知识与规则，而非通过自主学习获得。

1.1.1 物理符号系统假说

符号主义时代的理论基础，是 1976 年艾伦·纽厄尔（Allen Newell）与赫伯特·西蒙（Herbert A. Simon）提出的物理符号系统假说（Physical Symbol System Hypothesis，PSSH）。这一假说包含两个核心观点：

  • 充分性：任何物理符号系统都具备产生通用智能行为的充分条件。
  • 必要性：凡是能够展现通用智能行为的系统，其本质必然是物理符号系统。

所谓物理符号系统，是指一种可在物理世界中实现的系统，由可区分的符号集合及一系列对符号进行操作的过程构成。符号可以组合成更复杂的结构，而这些过程能够创建、修改、复制或销毁符号结构。

1.1.2 专家系统

在物理符号系统假说的推动下，专家系统成为符号主义时代最具代表性的应用。其核心目标是模拟人类专家在特定领域中的问题解决能力，通过将专家的知识与经验形式化并编码为程序来实现。

专家系统的智能主要来源于两大核心组件：

  1. 知识库（Knowledge Base）：存储领域专家的知识与经验，最常见的表示方式是产生式规则——即”IF–THEN”形式的条件语句。例如：IF 出现发烧且咳嗽 THEN 可能为呼吸道感染。

  2. 推理机（Inference Engine）：作为系统的核心计算模块，依据用户提供的事实，在知识库中匹配并应用规则推导新结论。主要推理方式包括：

    • 正向链：从已知事实出发，逐步触发规则，属数据驱动推理。
    • 反向链：从目标假设出发，反向寻找支持证据，属目标驱动推理。

著名的专家系统包括医疗诊断系统 MYCIN 和积木世界理解系统 SHRDLU。

1.2 动手实践：构建基于规则的聊天机器人 ELIZA

ELIZA 是由 MIT 计算机科学家约瑟夫·魏泽鲍姆（Joseph Weizenbaum）于 1966 年推出的程序，是早期自然语言处理的重要尝试。它最著名的脚本 “DOCTOR” 模拟了罗杰斯学派的非指导性心理治疗师。

ELIZA 的机制十分简洁：它不直接回答问题，而是识别用户输入中的关键词，并依据预设的转换规则，将陈述改写为开放式提问。例如，当用户说”I am feeling sad”时，系统可能回应：“Why do you feel sad?”

Tip历史趣闻：ELIZA 效应

魏泽鲍姆并不试图让机器真正理解人类情感。然而令他意外的是，许多用户在与 ELIZA 交互后产生了情感依赖，甚至相信它能够理解自己。这种现象后来被称为ELIZA 效应——人类倾向于将智能属性投射到表面上像人类的机器行为上。这一效应至今仍在 ChatGPT 等现代 AI 产品中持续上演。

1.2.1 算法原理

ELIZA 的算法核心基于模式匹配与文本替换，分为四个步骤：

  1. 关键词识别与排序：系统为每个关键词设定优先级，优先匹配高优先级规则。
  2. 分解规则：利用包含通配符的分解规则提取句子其余部分。例如，规则 I need * 匹配 I need some help，捕获 some help。
  3. 重组规则：从关联的多条重组规则中随机选择一条生成回复，可引用已捕获内容。
  4. 代词转换：在生成回复前进行简单的代词替换（如 I → you，my → your），以保持对话自然。

1.2.2 Python 实现

import re
import random


# ============================================================
# 1. 规则库：模式 -> 响应模板列表
# ============================================================
RULES = {
    r"I need (.*)": [
        "Why do you need {0}?",
        "Would it really help you to get {0}?",
        "Are you sure you need {0}?",
    ],
    r"Why don'?t you ([^\?]*)\??": [
        "Do you really think I don't {0}?",
        "Perhaps eventually I will {0}.",
        "Do you really want me to {0}?",
    ],
    r"Why can'?t I ([^\?]*)\??": [
        "Do you think you should be able to {0}?",
        "If you could {0}, what would you do?",
        "I don't know -- why can't you {0}?",
    ],
    r"I am (.*)": [
        "Did you come to me because you are {0}?",
        "How long have you been {0}?",
        "How do you feel about being {0}?",
    ],
    r"I'?m (.*)": [
        "How does being {0} make you feel?",
        "Why do you think you're {0}?",
    ],
    r".* mother .*": [
        "Tell me more about your mother.",
        "What was your relationship with your mother like?",
        "How do you feel about your mother?",
    ],
    r".* father .*": [
        "Tell me more about your father.",
        "How did your father make you feel?",
        "What has your father taught you?",
    ],
    r".*": [
        "Please tell me more.",
        "Let's change focus a bit... Tell me about your family.",
        "Can you elaborate on that?",
    ],
}

# ============================================================
# 2. 代词转换表
# ============================================================
PRONOUN_SWAP = {
    "i": "you", "you": "i", "me": "you",
    "my": "your", "am": "are", "are": "am",
    "was": "were", "i'd": "you would",
    "i've": "you have", "i'll": "you will",
    "yours": "mine", "mine": "yours",
}


def swap_pronouns(phrase: str) -> str:
    """简单的代词互换"""
    words = phrase.lower().split()
    swapped = [PRONOUN_SWAP.get(w, w) for w in words]
    return " ".join(swapped)


def respond(user_input: str) -> str:
    """根据规则库生成回复"""
    for pattern, templates in RULES.items():
        match = re.match(pattern, user_input, re.IGNORECASE)
        if match:
            # 提取捕获组（如果有）
            captured = match.group(1) if match.lastindex else ""
            swapped = swap_pronouns(captured)
            # 随机选择一个模板并替换占位符
            template = random.choice(templates)
            return template.replace("{0}", swapped)
    return "I'm not sure I understand."


# ============================================================
# 3. 主聊天循环
# ============================================================
def main():
    print("Therapist: Hello! How can I help you today?")
    print("(Type 'quit' to exit)\n")

    while True:
        user_input = input("You: ")
        if user_input.lower() in ("quit", "exit", "bye"):
            print("Therapist: Goodbye. It was nice talking to you.")
            break
        response = respond(user_input)
        print(f"Therapist: {response}")


if __name__ == "__main__":
    main()

运行效果：

Therapist: Hello! How can I help you today?
(Type 'quit' to exit)

You: I am feeling sad today.
Therapist: How long have you been feeling sad today?
You: I need some help with my project.
Therapist: Are you sure you need some help with your project?
You: My mother is not happy with my work.
Therapist: Tell me more about your mother.
You: quit
Therapist: Goodbye. It was nice talking to you.

1.2.3 ELIZA 的局限与启示

通过亲手实现 ELIZA，我们可以直观感受到规则驱动系统的根本局限——这些问题正好印证了符号主义的理论挑战：

局限 表现 对现代 Agent 的启示
缺乏语义理解 “I am not happy” 仍会匹配 I am 规则，无法识别否定 Agent 需要真正的推理能力而非模式匹配
缺少上下文记忆 每次响应仅依赖当前输入，无法支持多轮对话 Agent 需要记忆系统（第 7 章）
规则扩展困难 规则数量增加后，冲突与优先级管理变得复杂 Agent 需要学习和泛化能力

1.3 马文·明斯基的心智社会

符号主义的发展与 ELIZA 的实践共同揭示了一个核心问题：依赖预设规则、由单一集中式推理引擎驱动的系统，难以通向真正的智能。这一困境促使马文·明斯基在《心智社会》中提出了颠覆性的观点：

“让我们变得智能的并非某种神奇技巧，而恰恰是没有单一技巧；智能的力量源于高度多样性，而非某个完美原则。”

在明斯基的框架中，智能不是由一个”万能大脑”实现的，而是由大量极其简单且高度专门化的心智智能体（mental agents）通过协作涌现出来的。例如，负责线条识别的 LINE-FINDER、负责抓握动作的 GRASP——这些简单智能体通过去中心化的激活与抑制信号相互作用，形成了”搭建积木塔”这样的复杂智能行为。

这一思想直接影响了现代多智能体系统（Multi-Agent System）的设计理念——我们将在第 9 章详细探讨。

1.4 学习范式的演进与现代智能体

符号主义的核心困境在于：智能无法被完整设计。这引出了一个关键问题：如果智能无法被完整设计，是否可以通过学习获得？

1.4.1 从符号到联结

作为对符号主义的回应，联结主义（Connectionism）在 20 世纪 80 年代重新兴起。其核心观点是：

  • 分布式知识表示：知识不再以显式符号或规则存储，而是以连接权重的形式分散存在于大量人工神经元之间。
  • 通过学习调整权重：系统能力来源于学习过程，通过样本数据不断调整连接权重。

这一范式转变标志着智能体构建思想的根本变化：符号主义强调”教会机器知识”，而联结主义则致力于”让机器学会知识”。

1.4.2 基于强化学习的智能体

联结主义擅长解决感知问题（“图像中是什么”），而智能体更核心的任务在于决策（“此时应采取什么行动”）。强化学习（Reinforcement Learning, RL）正是面向序贯决策的学习范式，其核心是通过与环境交互、试错来学习如何最大化长期回报。

以 AlphaGo 为例：智能体根据棋盘状态选择落子行动，对局结束后根据胜负获得奖励或惩罚。通过数百万次自我对弈，系统不断调整内部策略——这一过程无需人类棋谱的直接指导。

1.4.3 大型语言模型的诞生与涌现能力

预训练—微调范式彻底改变了 NLP 领域。通过在数万亿级文本上的预训练，大型语言模型的神经网络权重形成了一个高度压缩的、关于世界知识的隐式模型。更为关键的是，当模型规模跨越临界点后，会涌现出并未被显式训练的能力：

  • 上下文学习（In-Context Learning）：无需更新权重，仅通过输入中的少量示例即可完成新任务。
  • 思维链推理（Chain-of-Thought）：引导模型先输出逐步推理过程，可显著提升复杂推理表现。

至此，智能体发展的关键技术要素已逐步齐备：符号主义奠定逻辑推理框架，联结主义与强化学习赋予学习与决策能力，而大型语言模型则提供了通过预训练获得的广泛世界知识与通用推理能力。这正是我们在本书中构建 LLM Agent 的技术基石。

1.5 本章小结

本章我们沿着时间线走过了智能体的演进历程：

  • 符号主义时代（1950s-1980s）：用规则和逻辑构建智能，代表作品为 ELIZA 和专家系统
  • 心智社会理论（1980s）：提出智能是大量简单智能体协作的涌现结果
  • 联结主义与强化学习（1980s-2010s）：让机器从数据中学习，代表作品为 AlphaGo
  • 大语言模型时代（2020s-至今）：预训练 + 涌现能力，催生了现代 LLM Agent

亲手实现的 ELIZA 让我们体会到规则系统的局限，也让我们更加理解为什么需要 LLM 这样的通用推理引擎来驱动现代智能体。
