2  The history of agent development

2.1 基于符号与逻辑的早期智能体

人工智能的早期研究深受数理逻辑与计算机科学基础理论的影响。研究者普遍认为，人类智能，尤其是逻辑推理能力，可以通过形式化的符号体系加以刻画和实现。这一理念催生了人工智能的首个重要范式——符号主义（Symbolicism），亦称“逻辑 AI”或“传统 AI”。

在符号主义框架下，智能被视为对符号依据明确规则进行操作的过程。智能体被建模为物理符号系统：利用内部符号表示外部世界，并通过逻辑推理来规划和决策。此类智能体的能力完全来源于设计者预先编写的知识与规则，而非通过自主学习获得。

2.1.1 物理符号系统假说

符号主义时代的理论基础，是 1976 年艾伦·纽厄尔（Allen Newell）与赫伯特·西蒙（Herbert A. Simon）提出的物理符号系统假说（Physical Symbol System Hypothesis，PSSH）[1]。这一假说为在计算机上实现通用人工智能提供了重要的理论框架与判定标准。

该假说包含两个核心观点：

  • 充分性：任何物理符号系统都具备产生通用智能行为的充分条件。

  • 必要性：凡是能够展现通用智能行为的系统，其本质必然是物理符号系统。

所谓物理符号系统，是指一种可在物理世界中实现的系统，由可区分的符号集合及一系列对符号进行操作的过程构成 ）。符号可以组合成更复杂的结构，而这些过程能够创建、修改、复制或销毁符号结构。

2.1.2 专家系统

在物理符号系统假说的推动下，专家系统成为符号主义时代最具代表性、也最成功的应用。其核心目标是模拟人类专家在特定领域中的问题解决能力。通过将专家的知识与经验形式化并编码为程序，专家系统能够在类似情境下给出接近甚至超过人类专家水平的判断与建议。

专家系统的智能主要来源于两大核心组件：知识库与推理机。

  1. 知识库（Knowledge Base）：用于存储领域专家的知识与经验，其构建关键在于知识表示。专家系统中最常见的表示方式是产生式规则，即“IF–THEN”形式的条件语句，用于将特定情境与相应结论或行动关联起来。例如：IF 出现发烧且咳嗽 THEN 可能为呼吸道感染。大量规则相互关联，构成完整的知识体系。

  2. 推理机（Inference Engine）：作为系统的核心计算模块，推理机依据用户提供的事实，在知识库中匹配并应用规则，从而推导新结论。其主要推理方式包括：

  • 正向链：从已知事实出发，逐步触发规则并生成新事实，属于数据驱动推理。
  • 反向链：从目标假设出发，反向寻找支持该目标的规则并验证条件，属于目标驱动推理。

2.2 构建基于规则的聊天机器人

ELIZA 是由麻省理工学院计算机科学家约瑟夫·魏泽鲍姆（Joseph Weizenbaum）于 1966 年推出的计算机程序，是早期自然语言处理的重要尝试之一。它并非单一应用，而是一个可运行不同“脚本”的框架，其中最著名的是 “DOCTOR” 脚本，用以模拟罗杰斯学派的非指导性心理治疗师。

ELIZA 的机制十分简洁：它不直接回答问题，而是识别用户输入中的关键词，并依据预设的转换规则，将陈述改写为开放式提问。例如，当用户说“我为我的男朋友感到难过”时，系统可能生成回应：“你为什么会为你的男朋友感到难过？”

魏泽鲍姆并不试图让机器真正理解人类情感，相反，他希望借此说明：即便完全不理解对话内容，简单的句式转换也能制造出“智能”与“共情”的表象。然而，令他意外的是，许多用户在与 ELIZA 交互后产生了情感依赖，甚至相信它能够理解自己。

2.2.1 模式匹配与文本替换

ELIZA 的算法核心基于模式匹配与文本替换，其流程可概括为四个步骤：

  1. 关键词识别与排序：系统为每个关键词设定优先级，当输入中包含多个关键词时，优先匹配优先级最高者对应的规则。

  2. 分解规则：确定关键词后，利用包含通配符（）的分解规则提取句子其余部分。

  • 示例：
  • 规则： my *
  • 输入：“My mother is afraid of me”
  • 结果：[““,”mother is afraid of me”]
  1. 重组规则：从与分解规则关联的多条重组规则中选择一条生成回复，通常随机选取以增强多样性，并可引用已捕获的内容。
  • 示例：
  • 规则：“Tell me more about your family.”
  • 输出：“Tell me more about your family.”
  1. 代词转换：在生成回复前进行简单的代词替换（如 I→you，my→your），以保持对话自然连贯。

2.2.2 核心逻辑的实现

library(stringr)

# ---------------------------
# 1. 定义规则库（pattern -> responses）
# ---------------------------

rules <- list(
  "I need (.*)" = c(
    "Why do you need {0}?",
    "Would it really help you to get {0}?",
    "Are you sure you need {0}?"
  ),

  "Why don't you (.*)\\?" = c(
    "Do you really think I don't {0}?",
    "Perhaps eventually I will {0}.",
    "Do you really want me to {0}?"
  ),

  "Why can't I (.*)\\?" = c(
    "Do you think you should be able to {0}?",
    "If you could {0}, what would you do?",
    "I don't know -- why can't you {0}?"
  ),

  "I am (.*)" = c(
    "Did you come to me because you are {0}?",
    "How long have you been {0}?",
    "How do you feel about being {0}?"
  ),

  ".* mother .*" = c(
    "Tell me more about your mother.",
    "What was your relationship with your mother like?",
    "How do you feel about your mother?"
  ),

  ".* father .*" = c(
    "Tell me more about your father.",
    "How did your father make you feel?",
    "What has your father taught you?"
  ),

  ".*" = c(
    "Please tell me more.",
    "Let's change focus a bit... Tell me about your family.",
    "Can you elaborate on that?"
  )
)

# ---------------------------
# 2. 代词转换规则
# ---------------------------

pronoun_swap <- c(
  "i" = "you",
  "you" = "i",
  "me" = "you",
  "my" = "your",
  "am" = "are",
  "are" = "am",
  "was" = "were",
  "i'd" = "you would",
  "i've" = "you have",
  "i'll" = "you will",
  "yours" = "mine",
  "mine" = "yours"
)

swap_pronouns <- function(phrase) {
  words <- str_split(tolower(phrase), "\\s+")[[1]]
  swapped <- sapply(words, function(w) {
    if (w %in% names(pronoun_swap)) pronoun_swap[[w]] else w
  })
  paste(swapped, collapse = " ")
}

# ---------------------------
# 3. 生成回应
# ---------------------------

respond <- function(user_input) {

  for (pattern in names(rules)) {

    match <- str_match(user_input, regex(pattern, ignore_case = TRUE))

    if (!is.na(match[1, 1])) {

      # 捕获分组（如果有）
      captured <- if (ncol(match) > 1) match[1, 2] else ""
      swapped  <- swap_pronouns(captured)

      # 随机选一个模板
      template <- sample(rules[[pattern]], 1)

      # 替换 {0}
      response <- str_replace(template, "\\{0\\}", swapped)

      return(response)
    }
  }

  # 理论上不会走到这里（因为有 .*）
  sample(rules[[".*"]], 1)
}

# ---------------------------
# 4. 主聊天循环
# ---------------------------

cat("Therapist: Hello! How can I help you today?\n")

repeat {
  user_input <- readline("You: ")

  if (tolower(user_input) %in% c("quit", "exit", "bye")) {
    cat("Therapist: Goodbye. It was nice talking to you.\n")
    break
  }

  response <- respond(user_input)
  cat("Therapist:", response, "\n")
}

通过上述实践，可以直观总结出规则驱动系统的根本局限，这些问题正好印证了符号主义的理论挑战：

  • 缺乏语义理解：系统不具备词义层面的理解能力。例如面对“I am not happy”，仍会机械匹配规则并生成不合语义的回应，无法识别否定关系。

  • 缺少上下文记忆：系统是无状态的，每次响应仅依赖当前输入，无法支持连贯的多轮对话。

  • 规则扩展困难：随着规则数量增加，规则库规模迅速膨胀，冲突与优先级管理变得复杂，系统难以维护。

尽管存在明显缺陷，ELIZA 在当时却引发了著名的“ELIZA 效应”，许多用户误以为它能够理解自己。这种智能幻觉主要源于其对话策略（如被动提问、开放式模板）以及人类天然的情感投射。

ELIZA 的实践揭示了符号主义的核心矛盾：表面上的智能完全依赖人工编码的规则。面对真实语言的无限变化，这种穷举式方法不可扩展。系统并不理解意义，只是在操作符号，这正是其根本脆弱性的来源。

2.3 马文·明斯基的心智社会

符号主义的发展与 ELIZA 的实践共同揭示了一个核心问题：依赖预设规则、由单一集中式推理引擎驱动的系统，难以通向真正的智能。无论规则库多么庞大，在面对现实世界的模糊性、复杂性与无限变化时，这类系统始终显得僵硬而脆弱。

这一困境促使部分思想家开始反思人工智能的根本设计理念。马文·明斯基并未选择继续强化单一推理核心，而是在《心智社会》中提出了颠覆性的观点：“让我们变得智能的并非某种神奇技巧，而恰恰是没有单一技巧；智能的力量源于高度多样性，而非某个完美原则。”

2.3.1 对单一整体智能模型的反思

20 世纪 70 至 80 年代，符号主义的局限逐渐暴露。专家系统虽在垂直领域有效，却缺乏常识；SHRDLU只能理解封闭的积木世界；ELIZA能够模仿对话，却不理解内容本身。这些系统都采用自上而下的设计：由一个集中式的“全能”推理核心，依据统一规则处理信息并决策，结果在真实世界的复杂性面前显得僵化而脆弱。

在此背景下，明斯基提出了一系列根本性反思：

  • 什么是理解：理解是否是一种单一能力，还是多种心智过程（视觉、推理、情感、社会常识等）的协同结果？

  • 什么是常识：它是庞大的逻辑规则库，还是由分布式经验与简单规则片段交织而成的网络？

  • 智能体如何构建：应追求统一完美的逻辑系统，还是承认智能本质上由多样、甚至相互冲突的简单模块构成？

这些问题直指整体式智能模型的缺陷：试图用统一表示与推理机制解决一切，与自然智能的实际运作方式相悖。明斯基认为，将多样化心智活动强行纳入僵硬逻辑框架，正是早期 AI 停滞的根源。

基于此，他提出了颠覆性构想：不再将心智视为层级金字塔，而是看作一个扁平、由大量相互作用与协作单元构成的“社会”。

2.3.2 作为协作体的智能

在明斯基的框架中，智能体的含义不同于第一章所述的现代智能体。这里的智能体是极其简单且高度专门化的心智过程，本身并不具备“理解”能力。例如，负责线条识别的 LINE-FINDER，或负责抓握动作的 GRASP。

这些简单智能体通过组织形成更高层次的机构（Agency）。机构是一组协同运作的智能体，用于完成更复杂的任务。例如，用于搭积木的 BUILD 机构，可能由 SEE、FIND、GET、PUT 等多个下层智能体或子机构组成。它们通过去中心化的激活与抑制信号相互作用，形成动态的控制过程。

涌现是理解心智社会理论的核心。复杂且有目的的智能行为，并非由某个高层模块统一规划，而是源自大量简单智能体之间的局部交互。

以“搭建积木塔”为例 ：当高层目标“搭一个塔”出现时，会激活 BUILD-TOWER 机构。

  • BUILD-TOWER 本身不执行具体动作，只负责激活下属的 BUILDER 机构。
  • BUILDER 的逻辑同样简单：只要任务未完成，就反复激活 ADD-BLOCK 机构。
  • ADD-BLOCK 进一步协调 FIND-BLOCK、GET-BLOCK 和 PUT-ON-TOP 等子机构。 这些子机构又由更底层的智能体组成，例如 GET-BLOCK 会激活 SEE-SHAPE、REACH 和 GRASP 等智能体。

在整个过程中，没有任何单一智能体掌握全局计划。GRASP 只负责抓取，BUILDER 只负责循环控制。然而，当这些“无心”的智能体依照简单规则相互作用时，搭建积木塔这一看似复杂的智能行为便自然涌现出来。

2.3.3 对多智能体系统的理论启发

2.4 学习范式的演进与现代智能体

前文所述的“心智社会”理论在哲学层面为群体智能与去中心化协作提供了方向，但具体实现仍不清晰。与此同时，符号主义在真实世界复杂性面前暴露出的根本缺陷，也表明单靠预先编码的规则难以构建真正鲁棒的智能。

这两条思路共同引出了一个关键问题：如果智能无法被完整设计，是否可以通过学习获得？

由此，人工智能进入了“学习”范式。研究重点从手工编写知识，转向构建能够从经验与数据中自动获取能力的系统。本节将回顾这一范式的演进：从联结主义奠定学习基础，到强化学习实现交互式学习，再到当今由大语言模型驱动的现代智能体。

2.4.1 从符号到联结

作为对符号主义局限的直接回应，联结主义在 20 世纪 80 年代重新兴起。不同于符号主义自上而下、依赖明确规则的设计思路，联结主义采用自下而上的方法，灵感源自对生物神经网络结构的模拟，其核心观点包括：

  • 分布式知识表示：知识不再以显式符号或规则存储，而是以连接权重的形式分散存在于大量人工神经元之间，网络整体的连接结构即构成知识。
  • 简单处理单元：单个神经元仅执行简单计算，对加权输入进行激活处理并输出结果。
  • 通过学习调整权重：系统能力来源于学习过程，通过样本数据和学习算法不断调整连接权重，使输出逐步逼近期望目标。

在这一范式下，智能体不再是被动执行规则的推理机器，而是能够通过经验持续优化的适应性系统。这标志着智能体构建思想的根本转变：符号主义强调“教会机器知识”，而联结主义则致力于“让机器学会知识”。

2.4.2 基于强化学习的智能体

联结主义主要擅长解决感知问题（如“图像中是什么”），而智能体更核心的任务在于决策（如“此时应采取什么行动”）。强化学习（Reinforcement Learning, RL）正是面向序贯决策的学习范式。它不依赖标注好的静态数据，而是通过智能体与环境的交互，在试错过程中学习如何最大化长期回报。

以 AlphaGo 为例，其自我对弈过程是强化学习的典型实践。AlphaGo 作为智能体，根据棋盘状态选择落子行动；对局结束后，根据胜负获得奖励或惩罚。通过数百万次自我对弈，系统不断调整内部策略，逐步学会在不同局面下选择最有利于取胜的行动，这一过程无需人类棋谱的直接指导。

这种通过与环境互动、依据反馈信号优化行为的机制，构成了强化学习的核心思想。其基本框架可概括为以下要素：

  • 智能体（Agent）：学习与决策的主体。
  • 环境（Environment）：智能体所处并与之交互的外部系统。
  • 状态（State）：对环境当前情况的描述，是决策依据。
  • 行动（Action）：智能体在给定状态下可采取的操作。
  • 奖励（Reward）：环境对行动结果的反馈信号，用于评估行动优劣。

基于上述核心要素，强化学习智能体在一个“感知-行动-学习”的闭环中持续迭代

该循环可具体表述为以下步骤，可直接用于 Rmarkdown：

在时间步 \(t\)，智能体观察环境的当前状态 \(S_t\)。

基于状态 \(S_t\)，智能体依据其策略（Policy，\(\pi\)）选择并执行一个行动 \(A_t\)。策略本质上是从状态到行动的映射，决定了智能体的行为方式。

环境接收到行动 \(A_t\) 后，转移到新的状态 \(S_{t+1}\)。

同时，环境向智能体反馈一个即时奖励 \(R_{t+1}\)。

智能体利用新的状态 \(S_{t+1}\) 与奖励 \(R_{t+1}\) 更新其内部策略，以在未来做出更优决策，这一过程即为学习。

强化学习的目标不是最大化单一时间步的即时奖励，而是最大化从当前时刻开始的累积奖励（回报，Return），其定义为：

\[ G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \]

其中，\(\gamma \in [0,1]\) 为折扣因子，用于权衡即时奖励与未来奖励。

因此，智能体需要具备长期视角，有时需牺牲短期收益以换取更大的未来回报（例如围棋中的“弃子”）。通过不断重复上述交互—学习循环，智能体最终能够在复杂动态环境中实现自主决策与长期规划。

2.4.3 基于大规模数据的预训练

强化学习使智能体能够通过交互学习决策策略，但这一过程往往依赖大量面向特定任务的数据，使智能体在初期几乎没有先验认知，需要从零建立对任务的理解。无论是符号主义中人工编码的常识，还是人类决策所依赖的背景知识，在 RL 智能体中通常都是缺失的。由此引出了一个关键问题：如何在学习具体任务之前，就让智能体具备对世界的广泛理解？这一答案最终在自然语言处理领域中出现，其核心便是大规模数据驱动的预训练。

2.4.3.1 从特定任务到通用模型

在预训练范式出现之前，传统 NLP 模型通常针对单一任务（如情感分析或机器翻译），在规模有限、专门标注的数据集上从头训练。这种方式导致模型知识面狭窄、跨任务泛化能力弱，且每个新任务都需要高昂的数据标注成本。

  • 预训练—微调范式彻底改变了这一局面，其核心包括两个阶段：
  • 预训练阶段：在包含海量文本的通用语料上，通过自监督学习训练大规模神经网络模型。目标并非解决具体任务，而是学习语言的统计规律、语法结构、事实知识与上下文关系，常见任务是预测下一个词。

微调阶段：在完成预训练后，模型已具备丰富的通用知识，只需利用少量下游任务的标注数据进行微调，即可高效适配具体任务。

2.4.3.2 大型语言模型的诞生与涌现能力

通过在数万亿级文本上的预训练，大型语言模型的神经网络权重形成了一个高度压缩的、关于世界知识的隐式模型，从根本上缓解了符号主义时代最棘手的“知识获取瓶颈”。更为关键的是，当模型规模（参数、数据与计算）跨越临界点后，会涌现出并未被显式训练的能力，例如：

  • 上下文学习：无需更新权重，仅通过输入中的少量示例甚至零示例，模型即可完成新任务。
  • 思维链推理：引导模型先输出逐步推理过程，可显著提升其在逻辑、算术与常识推理中的表现。

这些现象表明，LLM 已不再只是语言建模工具，而是同时扮演了大规模知识库与通用推理引擎的角色。

至此，智能体发展的关键技术要素已逐步齐备：符号主义奠定逻辑推理框架，联结主义与强化学习赋予学习与决策能力，而大型语言模型则提供了通过预训练获得的广泛世界知识与通用推理能力。下一节将展示这些技术如何在现代智能体设计中实现融合。

2.4.4 基于大语言模型的智能体

随着大型语言模型的快速演进，以 LLM 为核心的智能体正成为人工智能的新范式。它们不仅具备强大的语言理解与生成能力，更能够在与环境的交互中，自主完成感知、规划、决策与执行等关键任务。

智能体与环境的交互可抽象为一个核心闭环。LLM 驱动的智能体通过多模块协同、持续迭代的流程完成任务，其整体架构如图 2.10 所示，主要包括以下步骤：

  1. 感知（Perception）：流程始于感知模块。智能体通过传感器从环境中获取原始输入，形成观察信息，如用户指令、API 返回结果或环境状态变化。这些处理后的观察将作为后续决策的基础。
  2. 思考（Thought）：这是智能体的认知核心，由规划模块与 LLM 协同完成。
  • 规划与分解：规划模块基于观察进行高层策略制定，通过反思与自我批判，将宏观目标拆解为可执行的子步骤。
  • 推理与决策：LLM 在整合规划指令与记忆信息后进行推理，最终决定下一步行动，通常以工具调用的形式给出。
  1. 行动（Action）：执行模块接收 LLM 生成的指令，从工具箱中选择并调用合适的工具（如代码执行、搜索或 API），与环境进行实际交互，从而完成行动。
  2. 观察与循环（Observation & Loop）：行动会改变环境并产生结果。工具返回的执行结果与更新后的环境状态共同构成新的观察。一方面，这些信息被感知模块捕获；另一方面，LLM 根据结果更新记忆，从而启动下一轮“感知—思考—行动”的循环。

正是这种模块化协作与持续迭代的闭环机制，构成了 LLM 驱动智能体解决复杂问题的核心工作流程。

2.4.5 智能体发展关键节点概览

人工智能体的发展并非线性演进，而是多种核心思想在半个多世纪中相互交织、竞争并逐步融合的过程。理解这一历史，有助于把握当代智能体架构形成的深层原因。

其中，三大思潮在不同时期主导了研究范式：

  • 符号主义（Symbolism）：以赫伯特·西蒙和马文·明斯基为代表，认为智能源于符号操作与逻辑推理，催生了 SHRDLU、专家系统以及在国际象棋领域取得突破的“深蓝”。
  • 联结主义（Connectionism）：受神经网络启发，在反向传播算法推动下复兴，并在深度学习时代通过卷积神经网络与 Transformer 成为主流方法。
  • 行为主义（Behaviorism）：强调通过与环境交互和试错学习策略，其现代形式为强化学习，从 TD-Gammon 到 AlphaGo，赋予智能体从经验中习得复杂决策的能力。

进入 21 世纪 20 年代，这些思想以前所未有的方式融合。以 GPT 系列为代表的大语言模型，虽源自联结主义，却承担起符号推理、工具调用与规划决策的核心角色，形成神经—符号结合的现代智能体架构。图 2.11 系统梳理了自 20 世纪 50 年代以来人工智能体发展的关键理论、项目与事件，为本章提供整体脉络的总结。

得益于大语言模型的突破，智能体技术栈呈现出前所未有的活跃度和多样性。
