6  Build your agent framework

6.1 构建你的智能体框架：HelloAgents

智能体技术发展很快，框架也迭代得很快。对学习者而言，最常见的困境并不是“找不到框架”，而是“框架太多、概念太多、接口变化太快”，最终只会停留在“会调用”，却难以在项目中稳定落地，更难以进行深度定制。

本章的目标不是再介绍一个新框架，而是带你完成一次关键能力跃迁：从框架使用者，变为框架构建者。我们将从零搭建一个轻量、可读、可扩展的智能体框架 HelloAgents，并通过版本迭代的方式逐步增强它的能力，使其成为后续章节（记忆、RAG、上下文工程、协议与插件系统等）的稳定底座。

为了保证学习过程可复现，本章强调三个原则：结构先行、接口统一、渐进演进。你将看到每一个模块为何存在、边界在哪里、与其他模块如何协作，并最终形成对智能体框架的“结构级掌握”。

6.2 为什么要自建智能体框架

在开始写代码前，我们先明确“为什么要自己搭框架”。这不是为了重复造轮子，而是为了掌握轮子的结构与制造方法。对工程团队而言，智能体系统往往会长期运行、持续演进，短期的“能跑”并不稀缺，稀缺的是“能维护、能扩展、能治理”。

现实里，成熟框架通常带来四类工程成本。

第一类是抽象成本。为了兼容更多场景，框架往往引入大量抽象层与配置项。初学者可能需要先理解一串概念，才能完成一个非常简单的任务。学习路径因此被拉长，且难以形成稳定直觉。

第二类是升级成本。智能体领域迭代频繁，接口变更也频繁。项目一旦进入维护期，框架升级导致的破坏性变更，会显著抬高维护成本，甚至迫使团队“冻结版本”，从而错过关键能力更新。

第三类是黑盒成本。很多框架为了封装易用性，把核心逻辑隐藏得很深。出现问题时，开发者只能依赖文档与社区，难以在代码层面做精确定位与深度定制。

第四类是依赖成本。通用框架常常携带大量依赖，既增加安装体积，也容易在与既有项目集成时引发依赖冲突；而在企业环境中，依赖冲突往往意味着部署风险与交付延期。

自建框架带来的价值，则集中体现在三种能力上：你能真正理解智能体的运行机制；你能对关键路径拥有控制权；你能训练系统设计能力，把智能体从“玩具”变成“工程”。

6.3 HelloAgents 的设计理念

HelloAgents 并不追求“大而全”，它追求的是“少而清晰”，并围绕教学与工程落地做取舍。

6.3.1 轻量与可读性优先

HelloAgents 把可读性视为第一指标。代码结构分层明确、模块职责单一、依赖尽可能少。这样做的直接收益是：学习者能在合理时间内读完核心代码，并在遇到问题时优先定位到框架自身，而不是在复杂依赖链中排查。

6.3.2 基于标准接口的务实选择

HelloAgents 选择基于行业通行的 OpenAI 风格接口构建模型调用层。原因很简单：大量模型服务商与本地推理服务都会兼容这套接口，学习者掌握一套调用方式，就能在不同提供商之间迁移，避免被某个框架的私有抽象锁定。

6.3.3 渐进式学习路径

本章将以版本迭代推进开发：每次新增一个模块，都确保能运行、可测试、可回滚。渐进式演进让学习过程不依赖“跳跃式理解”，也 distribute 了工程复杂度，使读者能够随时停在一个稳定版本上做实验。

6.3.4 统一的工具抽象

HelloAgents 采取一个关键简化：除了 Agent 之外，一切能力扩展都以工具的形式接入。记忆、RAG、搜索、计算、甚至协议适配层，都可以被视为“可被智能体调用的能力模块”。这种统一抽象减少了学习者需要记忆的概念数量，并为后续扩展建立一致入口。

6.4 整体架构蓝图

在具体代码之前，我们先建立全局架构图景。HelloAgents 可以被理解为三层结构：核心框架层、Agent 实现层、工具系统层。

分层 关注点 输出物
核心框架层 统一接口与数据流、配置与异常、消息表示与历史管理 LLM 中枢、Message、Config、Agent 基类、异常体系
Agent 实现层 不同智能体范式如何在统一接口上实现 Simple、ReAct、Reflection、Plan-and-Solve 等
工具系统层 能力扩展机制，注册、发现、执行与编排 Tool 基类、Registry、工具链、异步执行等

这种分层的目标不是“架构好看”，而是让系统具备两种能力：上层范式可以自由变化，而底层骨架保持稳定；工具能力可以持续增加，但不会污染 Agent 主流程。

6.5 快速体验：用最小闭环建立直觉

在教学与工程实践中，最有效的进入方式是先跑通最小闭环：能对话、能积累历史、能切换模型提供商。下面给出一个最小可运行示例。

from dotenv import load_dotenv
from hello_agents import SimpleAgent, HelloAgentsLLM

load_dotenv()

llm = HelloAgentsLLM()  # 支持自动识别 provider / base_url / api_key

agent = SimpleAgent(
    name="AI助手",
    llm=llm,
    system_prompt="你是一个有用的AI助手，请用清晰、简洁的方式回答。"
)

print(agent.run("你好，介绍一下你自己。"))
print("history size:", len(agent.get_history()))

这段代码背后隐含了一个重要事实：我们将智能体运行抽象为一条清晰的主流程——构造消息、调用模型、写入历史、返回输出。本章的全部内容，都是围绕如何把这条主流程做得更稳、更可扩展。

6.6 模型调用中枢：HelloAgentsLLM

智能体框架的第一条生命线是模型调用。实际工程里，模型提供商可能来自云端（多家供应商），也可能来自本地推理服务（例如兼容 OpenAI 接口的本地服务）。如果每次切换模型都要修改大量业务代码，系统会迅速变得脆弱。

因此 HelloAgentsLLM 的定位非常明确：它是“模型调用中枢”，负责吸收外部差异，把上层代码稳定在统一接口上。

6.6.1 核心对象与主流程

在这一模块里，被持续处理的核心对象可以概括为两类：调用凭证与消息载荷。

对象 说明 为什么是核心
调用凭证 api_key、base_url、provider、model 等 决定请求发往哪里、用什么模型、如何鉴权
消息载荷 OpenAI 风格 messages 列表 决定模型看到什么上下文、如何响应

这两个对象的主流程通常是：解析配置 → 识别 provider → 初始化 client → 发起调用（流式或非流式）→ 返回结果。

6.6.2 多提供商支持的工程意义

多提供商支持并不等同于堆砌 if-else。更合理的理解是：把“差异点”限制在凭证解析与默认地址上，把“共性”沉淀为统一调用接口。只要不同服务都能兼容 OpenAI 风格接口，上层智能体无需关心其具体来源。

6.6.3 本地模型接入的关键点

本地推理服务的真正价值在于：数据隐私、成本控制、可离线运行。工程上最关键的是统一接口而非部署细节。只要本地服务暴露 OpenAI 兼容 API，上层调用就与云端一致，你的智能体代码无需修改。

典型的做法是在环境变量中配置 base_url，让 LLM 中枢自动识别并接入：

LLM_BASE_URL="http://localhost:11434/v1"
LLM_MODEL_ID="llama3"

然后 Python 侧继续保持零改动：

llm = HelloAgentsLLM()

6.6.4 自动检测机制：约定优于配置

为了降低用户配置负担，HelloAgentsLLM 可以实现自动检测 provider 的策略。工程上，自动检测机制的价值不在“智能”，而在“减少人为配置导致的错误”。

常见的检测信号包括：特定供应商的环境变量、base_url 的域名与端口特征、本地服务的标准端口等。其核心目的是：当用户只提供最少信息时，框架仍能推断出合理默认值，减少“跑不起来”的概率。

完整代码

# hello_agents/core/llm.py
# hello_agents/core/llm.py
import os
from typing import Any, Dict, Iterator, List, Optional, Sequence, Union

from openai import OpenAI

from config import Config
from message import Message, ensure_message

MessageLike = Union[Message, Dict[str, Any]]


class HelloAgentsLLM:
    """
    统一的 LLM 调用接口（OpenAI 兼容）

    参数优先级（高 -> 低）：
    1) 显式传参（__init__ 参数）
    2) 环境变量（env）
    3) Config（注入）
    4) 代码默认值（hard default）
    """

    def __init__(
        self,
        *,
        config: Optional[Config] = None,
        model: Optional[str] = None,
        api_key: Optional[str] = None,
        base_url: Optional[str] = None,
        provider: Optional[str] = None,
        temperature: Optional[float] = None,
        max_tokens: Optional[int] = None,
        timeout: Optional[int] = None,
    ):
        self.config = config or Config()

        # ---- 1) 解析 model/provider/temperature/max_tokens/timeout：显式 > env > config > default ----
        self.model = (
            model
            or os.getenv("LLM_MODEL_ID")
            or os.getenv("OPENAI_MODEL")
            or self.config.default_model
            or "gpt-4o-mini"
        )

        resolved_provider = (
            provider
            or os.getenv("LLM_PROVIDER")
            or self.config.default_provider
            or "auto"
        )
        self.provider = resolved_provider if resolved_provider else "auto"

        self.temperature = (
            temperature
            if temperature is not None
            else float(os.getenv("TEMPERATURE")) if os.getenv("TEMPERATURE") else self.config.temperature
        )

        self.max_tokens = (
            max_tokens
            if max_tokens is not None
            else int(os.getenv("MAX_TOKENS")) if os.getenv("MAX_TOKENS") else self.config.max_tokens
        )

        self.timeout = (
            timeout
            if timeout is not None
            else int(os.getenv("TIMEOUT")) if os.getenv("TIMEOUT") else self.config.timeout
        )

        # ---- 2) provider 自动检测（仅当 provider=auto）----
        if self.provider == "auto":
            self.provider = self._auto_detect_provider(api_key=api_key, base_url=base_url)

        # ---- 3) 解析凭证与 base_url（凭证仍由 LLM 负责，不放入 Config）----
        resolved_api_key, resolved_base_url = self._resolve_credentials(
            provider=self.provider,
            api_key=api_key,
            base_url=base_url,
        )

        if not resolved_api_key:
            raise ValueError(
                f"API key not found for provider='{self.provider}'. "
                f"Please set env var or pass api_key explicitly."
            )

        self.api_key = resolved_api_key
        self.base_url = resolved_base_url

        self._client = OpenAI(
            api_key=self.api_key,
            base_url=self.base_url,
            timeout=self.timeout,
        )

    # -------- provider detection / credentials --------

    def _auto_detect_provider(self, api_key: Optional[str], base_url: Optional[str]) -> str:
        if os.getenv("OPENAI_API_KEY"):
            return "openai"

        actual_base_url = base_url or os.getenv("LLM_BASE_URL")
        if actual_base_url:
            u = actual_base_url.lower()
            if "api.openai.com" in u:
                return "openai"
            if "localhost" in u or "127.0.0.1" in u:
                if ":11434" in u:
                    return "ollama"
                if ":8000" in u:
                    return "vllm"
                return "local"

        actual_api_key = api_key or os.getenv("LLM_API_KEY")
        if actual_api_key and actual_api_key.startswith("sk-"):
            return "openai"

        return "auto"

    def _resolve_credentials(self, provider: str, api_key: Optional[str], base_url: Optional[str]) -> tuple[str, str]:
        common_key = os.getenv("LLM_API_KEY")
        common_base = os.getenv("LLM_BASE_URL")

        if provider == "openai":
            resolved_api_key = api_key or os.getenv("OPENAI_API_KEY") or common_key
            resolved_base_url = base_url or common_base or "https://api.openai.com/v1"
            return resolved_api_key, resolved_base_url

        if provider == "ollama":
            resolved_api_key = api_key or common_key or "ollama"
            resolved_base_url = base_url or common_base or "http://localhost:11434/v1"
            return resolved_api_key, resolved_base_url

        if provider == "vllm":
            resolved_api_key = api_key or common_key or "vllm"
            resolved_base_url = base_url or common_base or "http://localhost:8000/v1"
            return resolved_api_key, resolved_base_url

        resolved_api_key = api_key or common_key or os.getenv("OPENAI_API_KEY")
        resolved_base_url = base_url or common_base or "https://api.openai.com/v1"
        return resolved_api_key, resolved_base_url

    # -------- message normalization --------

    def _normalize_messages(self, messages: Sequence[MessageLike]) -> List[Dict[str, Any]]:
        normalized: List[Dict[str, Any]] = []
        for item in messages:
            m = ensure_message(item)
            normalized.append(m.to_openai_dict())
        return normalized

    # -------- invocation APIs --------

    def invoke(self, messages: Sequence[MessageLike], **kwargs) -> str:
        normalized = self._normalize_messages(messages)
        req = self._build_request_kwargs(**kwargs)
        completion = self._client.chat.completions.create(
            model=self.model,
            messages=normalized,
            **req,
        )
        return (completion.choices[0].message.content or "").strip()

    def think(self, messages: Sequence[MessageLike], **kwargs) -> Iterator[str]:
        normalized = self._normalize_messages(messages)
        req = self._build_request_kwargs(**kwargs)
        stream = self._client.chat.completions.create(
            model=self.model,
            messages=normalized,
            stream=True,
            **req,
        )
        for event in stream:
            delta = event.choices[0].delta
            text = getattr(delta, "content", None)
            if text:
                yield text

    def stream_invoke(self, messages: Sequence[MessageLike], **kwargs) -> Iterator[str]:
        return self.think(messages, **kwargs)

    def _build_request_kwargs(self, **kwargs) -> Dict[str, Any]:
        req: Dict[str, Any] = dict(kwargs)
        req.setdefault("temperature", self.temperature)
        if self.max_tokens is not None:
            req.setdefault("max_tokens", self.max_tokens)
        return req




if __name__ == "__main__":
    # llm = HelloAgentsLLM(model="gemma3:12b",base_url="http://localhost:11434/v1")
    from dotenv import load_dotenv

    load_dotenv()

    # 1) 从环境变量加载行为配置（不含 API key）
    cfg = Config.from_env().with_updates(
        temperature=0.2,
        max_history_length=50,
    )

    # 2) 把 cfg 注入 LLM（此时：env > cfg > default）
    llm = HelloAgentsLLM(config=cfg)

    messages = [
        Message(role="system", content="你是严谨的技术写作助教。"),
        Message(role="user", content="解释 Config 为什么要注入到框架中。"),
    ]

    print(llm.invoke(messages))

    # 3) 显式传参具有最高优先级（显式 > env > cfg > default）
    llm_override = HelloAgentsLLM(config=cfg, temperature=0.9)
    print(llm_override.invoke(messages))

6.7 消息系统：Message

智能体系统里，消息并不只是字符串。消息是上下文工程的最小单位，是历史、工具结果、系统提示词等信息的承载体。没有统一的消息表示，你无法稳定管理对话历史，更无法在后续章节把工具调用结果、检索证据、审计信息等纳入同一条数据流。

6.7.1 核心对象与主流程

消息系统里被持续处理的对象是“消息实体”。它至少需要包含 role 与 content，同时保留扩展空间。

字段 角色 工程意义
role user / assistant / system / tool 与模型接口对齐，确保可兼容
content 文本内容 对话语义的载体
metadata 可选信息 日志、追踪、来源引用、工具参数等扩展点
timestamp 时间戳 便于审计与调试

消息的主流程通常是：创建 → 进入历史 → 转为 API 格式 → 发给模型 → 作为下一轮上下文的一部分。

下面是一种典型的最小实现形式（保留扩展位但不引入复杂度）：

# hello_agents/core/message.py
from __future__ import annotations

from dataclasses import dataclass, field
from datetime import datetime, timezone
from typing import Any, Dict, Literal, Optional


MessageRole = Literal["user", "assistant", "system", "tool"]


@dataclass(frozen=True)
class Message:
    """
    框架内部的标准消息对象。

    设计原则：
    1) 内部强类型：role 受限、字段固定、默认值可控
    2) 对外兼容：可无损转换为 OpenAI messages 格式
    3) 可扩展：metadata 可承载工具调用、追踪、审计字段
    """

    content: str
    role: MessageRole
    timestamp: datetime = field(default_factory=lambda: datetime.now(timezone.utc))
    metadata: Dict[str, Any] = field(default_factory=dict)

    def to_openai_dict(self) -> Dict[str, Any]:
        """
        转换为 OpenAI 兼容的 messages 元素：
        {"role": "...", "content": "..."}
        工具相关信息保留在 metadata，由更上层的 Tool/Agent 负责注入 OpenAI tools 格式。
        """
        return {"role": self.role, "content": self.content}

    def with_metadata(self, **kwargs: Any) -> "Message":
        """
        返回一个携带新增 metadata 的新 Message（不可变对象风格）。
        """
        new_meta = dict(self.metadata)
        new_meta.update(kwargs)
        return Message(
            content=self.content,
            role=self.role,
            timestamp=self.timestamp,
            metadata=new_meta,
        )

    def compact(self, max_len: int = 160) -> str:
        """
        用于日志与调试的紧凑展示。
        """
        text = self.content.replace("\n", " ").strip()
        if len(text) > max_len:
            text = text[: max_len - 3] + "..."
        return f"[{self.role}] {text}"


def ensure_message(obj: Any, default_role: MessageRole = "user") -> Message:
    """
    便捷适配器：允许框架内部在过渡期接收 dict/str，并统一转换为 Message。
    - str -> Message(role=default_role)
    - dict -> Message(role=dict['role'], content=dict['content'])
    - Message -> 原样返回
    """
    if isinstance(obj, Message):
        return obj

    if isinstance(obj, str):
        return Message(content=obj, role=default_role)

    if isinstance(obj, dict):
        role = obj.get("role", default_role)
        content = obj.get("content", "")
        if role not in ("user", "assistant", "system", "tool"):
            raise ValueError(f"Invalid role in dict message: {role}")
        if not isinstance(content, str):
            content = str(content)
        return Message(content=content, role=role, metadata=obj.get("metadata", {}))

    raise TypeError(f"Cannot convert to Message: {type(obj)}")

if __name__ == "__main__":
    m1 = Message(content="你好", role="user")
    print(m1.to_openai_dict())
    print(m1.compact())

这里需要强调一个设计取向：内部 Message 可以逐步变“丰富”，但对外输出必须保持“兼容”。to_openai_dict() 就是对外兼容层，它让你未来升级 Message 结构时，不必推翻上层 Agent 的逻辑。

6.8 配置系统：Config

智能体系统的第二条生命线是配置管理。温度、最大 token、日志级别、历史长度等配置项，如果散落在业务代码中，会导致运行行为不可控，部署环境难以统一，排障成本显著提升。

Config 的目标是把这些参数集中管理，并提供合理默认值，使框架在“零配置”条件下仍可运行，同时支持通过环境变量覆盖配置。

6.8.1 配置对象与主流程

Config 模块的核心对象是“配置实体”。主流程是：构造默认配置 → 读取环境变量覆盖 → 提供给 Agent 与 LLM 层使用。

# hello_agents/core/config.py
from __future__ import annotations

import os
from dataclasses import dataclass, asdict, field
from typing import Any, Dict, Optional


def _get_env_bool(name: str, default: bool) -> bool:
    v = os.getenv(name)
    if v is None:
        return default
    return v.strip().lower() in ("1", "true", "yes", "y", "on")


def _get_env_int(name: str, default: Optional[int]) -> Optional[int]:
    v = os.getenv(name)
    if v is None or v.strip() == "":
        return default
    return int(v)


def _get_env_float(name: str, default: float) -> float:
    v = os.getenv(name)
    if v is None or v.strip() == "":
        return default
    return float(v)


def _get_env_str(name: str, default: Optional[str]) -> Optional[str]:
    v = os.getenv(name)
    if v is None or v.strip() == "":
        return default
    return v


@dataclass(frozen=True)
class Config:
    """
    框架统一配置对象。

    设计目标：
    - 零配置可用：默认值能让系统跑起来
    - 部署友好：支持从环境变量覆盖
    - 可注入：Agent/LLM 可显式传入 Config 替换默认配置
    - 可导出：to_dict 便于日志与调试

    覆盖优先级建议：
    显式参数 > 环境变量 > 默认值
    """

    # ---- LLM 相关（注意：api_key/base_url 更适合放在 env 或 LLM init 参数里）----
    default_model: str = "gpt-4o-mini"
    default_provider: str = "auto"
    temperature: float = 0.7
    max_tokens: Optional[int] = None
    timeout: int = 60

    # ---- 历史与对话管理 ----
    max_history_length: int = 100
    truncate_strategy: str = "drop_oldest"  # 预留：drop_oldest / summarize / window

    # ---- 运行与调试 ----
    debug: bool = False
    log_level: str = "INFO"  # INFO / DEBUG / WARN / ERROR

    # ---- 可扩展区域：工具、执行策略、保护栏等 ----
    extra: Dict[str, Any] = field(default_factory=dict)

    @classmethod
    def from_env(cls) -> "Config":
        """
        从环境变量构建 Config。仅覆盖已定义字段，不解析敏感凭证。
        建议你把凭证（OPENAI_API_KEY 等）留给 LLM 去解析，Config 只管“行为参数”。
        """
        return cls(
            default_model=_get_env_str("LLM_MODEL_ID", cls.default_model) or cls.default_model,
            default_provider=_get_env_str("LLM_PROVIDER", cls.default_provider) or cls.default_provider,
            temperature=_get_env_float("TEMPERATURE", cls.temperature),
            max_tokens=_get_env_int("MAX_TOKENS", cls.max_tokens),
            timeout=_get_env_int("TIMEOUT", cls.timeout) or cls.timeout,
            max_history_length=_get_env_int("MAX_HISTORY_LENGTH", cls.max_history_length) or cls.max_history_length,
            truncate_strategy=_get_env_str("TRUNCATE_STRATEGY", cls.truncate_strategy) or cls.truncate_strategy,
            debug=_get_env_bool("DEBUG", cls.debug),
            log_level=_get_env_str("LOG_LEVEL", cls.log_level) or cls.log_level,
        )

    def to_dict(self) -> Dict[str, Any]:
        """
        用于日志/调试/导出。extra 会被原样保留。
        """
        return asdict(self)

    def with_updates(self, **kwargs: Any) -> "Config":
        """
        返回一个带有更新字段的新 Config（不可变对象风格）。
        未知字段默认进入 extra，避免教学阶段被参数爆炸拖累。
        """
        data = self.to_dict()
        extra = dict(data.get("extra", {}))

        for k, v in kwargs.items():
            if k in data:
                data[k] = v
            else:
                extra[k] = v

        data["extra"] = extra
        return Config(**data)

6.9 Agent 抽象：统一入口与历史管理

Agent 是框架最核心的抽象，也是上层所有范式的统一落点。一个可扩展的智能体框架必须回答一个问题：无论你采用何种范式，智能体的执行入口在哪里？运行时的共同能力是什么？

HelloAgents 的最小回答是：所有 Agent 共享统一的运行入口，至少具备历史管理能力，并持有 LLM 中枢与系统提示词。

6.9.1 Agent 的核心对象

对象 说明 在系统中的角色
llm 模型调用中枢 负责与模型交互
system_prompt 系统提示词 定义行为边界与风格
history Message 列表 提供上下文，支持多轮对话
config 配置对象 控制运行策略

6.9.2 最小 Agent 基类

# hello_agents/core/agent.py
from __future__ import annotations

from abc import ABC, abstractmethod
from typing import Iterator, List, Optional, Sequence, Union

from .config import Config
from .llm import HelloAgentsLLM
from .message import Message


class Agent(ABC):
    """
    Agent 抽象基类：统一所有 Agent 范式的外部接口与内部骨架。

    约定：
    - history 使用 List[Message] 作为唯一内部消息格式
    - system_prompt 通过 system role 注入消息栈顶部
    - run() 作为稳定公开入口；子类只需实现 _execute()
    """

    def __init__(
        self,
        *,
        name: str,
        llm: HelloAgentsLLM,
        system_prompt: Optional[str] = None,
        config: Optional[Config] = None,
    ):
        self.name = name
        self.llm = llm
        self.system_prompt = system_prompt
        self.config = config or Config()
        self._history: List[Message] = []

    # ---------- public APIs ----------

    def run(self, input_text: str, **kwargs) -> str:
        """
        稳定公开入口：负责组装消息、调用执行、写入历史、截断历史。
        子类只需要实现 _execute(messages, **kwargs)。
        """
        messages = self._build_messages(input_text=input_text)

        if self.config.debug:
            self._debug_dump(messages, title="run() assembled messages")

        output_text = self._execute(messages=messages, **kwargs)

        # 写入历史：只落 user + assistant 两条（system 不进 history）
        self.add_message(Message(role="user", content=input_text))
        self.add_message(Message(role="assistant", content=output_text))

        # 截断历史
        self._truncate_history()

        return output_text

    def stream_run(self, input_text: str, **kwargs) -> Iterator[str]:
        """
        默认流式入口：基类给出一个通用实现。
        子类如果有更复杂行为（如工具循环），可以覆写此方法。
        """
        messages = self._build_messages(input_text=input_text)

        if self.config.debug:
            self._debug_dump(messages, title="stream_run() assembled messages")

        chunks = self._stream_execute(messages=messages, **kwargs)

        full = ""
        for c in chunks:
            full += c
            yield c

        # 写入历史
        self.add_message(Message(role="user", content=input_text))
        self.add_message(Message(role="assistant", content=full))
        self._truncate_history()

    def add_message(self, message: Message) -> None:
        self._history.append(message)

    def get_history(self) -> List[Message]:
        return list(self._history)

    def clear_history(self) -> None:
        self._history.clear()

    # ---------- template methods ----------

    @abstractmethod
    def _execute(self, *, messages: Sequence[Message], **kwargs) -> str:
        """
        子类实现：给定已组装的 messages，返回最终字符串。
        """
        raise NotImplementedError

    def _stream_execute(self, *, messages: Sequence[Message], **kwargs) -> Iterator[str]:
        """
        默认流式执行：直接走 llm.think。
        子类可覆写以支持多轮工具调用下的流式输出。
        """
        return self.llm.think(list(messages), **kwargs)

    # ---------- internal helpers ----------

    def _build_messages(self, *, input_text: str) -> List[Message]:
        """
        system + history + current user
        """
        msgs: List[Message] = []

        if self.system_prompt:
            msgs.append(Message(role="system", content=self.system_prompt))

        msgs.extend(self._history)
        msgs.append(Message(role="user", content=input_text))

        return msgs

    def _truncate_history(self) -> None:
        """
        最简历史截断策略：drop_oldest
        说明：history 是 user/assistant 成对增长，但不强制必须成对。
        """
        limit = self.config.max_history_length
        if limit is None or limit <= 0:
            return

        if len(self._history) <= limit:
            return

        strategy = (self.config.truncate_strategy or "drop_oldest").strip().lower()

        if strategy == "drop_oldest":
            # 丢弃最旧的消息，保留最新 limit 条
            self._history = self._history[-limit:]
            return

        # 预留：未来支持 summarize/window 等策略
        # 教学阶段先把策略做成可扩展接口，但实现只给 drop_oldest
        self._history = self._history[-limit:]

    def _debug_dump(self, messages: Sequence[Message], *, title: str) -> None:
        print(f"\n[DEBUG] {self.name} - {title}")
        for i, m in enumerate(messages, 1):
            print(f"  {i:02d}. {m.compact(200)}")

这份最小实现刻意保持简单，但已经具备框架化的关键要素：统一入口、可控历史、可注入配置。后续章节里，所有范式（ReAct、Reflection、Plan-and-Solve）都将以此为基础进行框架化，并共享历史与配置管理能力。

6.10 智能体范式

当我们把 LLM 调用、消息、配置、历史管理这些“框架骨架”搭好之后，接下来最关键的问题就变成了：不同智能体范式（Simple、ReAct、Reflection、Plan-and-Solve）到底差异在哪里？它们如何共享同一套底座，而又保持各自的行为特点？

在 HelloAgents 的视角里，范式差异并不体现在“有没有 Agent 类”，而体现在同一个对象在运行时被如何处理。

这里的核心对象可以用两句话概括：

  • 第一，输入任务（用户问题）是同一个，但不同范式会生成不同的执行轨迹。
  • 第二，执行轨迹可以被视为“状态机”：每一步都处在某个状态，并通过条件触发下一次状态迁移。

为了在结构层面站住，我们先给出一个统一范式对照表。它不是功能清单，而是“同一主流程在不同策略下的变化方式”。

范式 共同主流程 关键差异点 典型失败点 框架化后应对方式
Simple 构造消息 → 调用模型 → 写入历史 不强调工具与规划，强调稳定对话体验 历史堆叠导致上下文膨胀；行为边界不清 历史上限、系统提示词固定入口、可选工具能力
ReAct 多轮循环：思考 → 行动 → 观察 → 继续 引入工具调用与显式推理轨迹 格式漂移；工具调用不可解析；循环不收敛 严格输出格式、最大步数、统一 ToolRegistry
Reflection 生成 → 反思 → 改写（多轮） 引入自我评估与迭代优化 反思无信息增量；反复改写但质量不升 提前终止条件、质量评分阈值、迭代次数上限
Plan-and-Solve 先规划再执行：计划列表 → 逐步求解 强调可分解、可控执行顺序 计划不可解析；步骤不可执行；漂移成自由文本 计划强制结构化输出、literal_eval 解析、错误回退

本章后续的所有代码实现，都可以被理解为：在统一 Agent 抽象之上，给出不同的“运行策略（run strategy）”，并用一致的工具系统把能力扩展稳定下来。

6.11 SimpleAgent 的框架化落地

SimpleAgent 的价值并不是“简单”，而是“稳定”。它是所有能力演进的基线：只要能稳定完成多轮对话、维护历史，并在必要时调用工具，就具备了工程落地的最低闭环。

6.11.1 核心对象与主流程

SimpleAgent 持续处理的核心对象是“对话消息流”。

对象 在流程中的位置 需要保持的性质
system_prompt 每轮对话的最前置约束 稳定、明确、可控
history messages 上下文记忆载体 有界、可裁剪
current input 本轮用户输入 必须进入历史
model response 模型输出 必须进入历史

其主流程保持极简：构造 messages（system + history + input）→ 调用 LLM → 返回响应 → 写入历史。

当我们引入“可选工具调用”能力时，主流程不会改变，只是会在“得到模型输出之后”增加一个分支：如果输出包含工具调用意图，则进入工具执行子流程。

6.11.2 状态与状态变化

为了让工具调用可解释，我们把 SimpleAgent 的运行状态显式化：

状态 含义 迁移条件
构造消息 system + history + input 组装 组装完成进入调用模型
调用模型 请求 LLM 得到响应文本 得到文本进入解析工具调用
解析工具调用 检查响应是否包含工具指令 有工具指令进入执行工具；否则进入收尾
执行工具 调用 ToolRegistry 得到结果 结果写入消息后回到调用模型（可选多轮）
收尾写历史 写入 user 与 assistant 完成返回结果

6.11.3 实现

        config=None,
        tool_registry: Optional[ToolRegistry] = None,
        enable_tool_calling: bool = True,
        max_tool_iterations: int = 3,
    ):
        super().__init__(name=name, llm=llm, system_prompt=system_prompt, config=config)
        self.tool_registry = tool_registry
        self.enable_tool_calling = enable_tool_calling and tool_registry is not None
        self.max_tool_iterations = max_tool_iterations

    def _execute(self, *, messages: Sequence[Message], **kwargs) -> str:
        if not self.enable_tool_calling:
            if getattr(self.config, "debug", False):
                print("[DEBUG] tool calling disabled -> direct llm.invoke")
            return self.llm.invoke(list(messages), **kwargs)

        working: List[Message] = list(messages)
        for i in range(self.max_tool_iterations):
            text = self.llm.invoke(working, **kwargs)
            calls = self._parse_tool_calls(text)

            if getattr(self.config, "debug", False):
                print(f"[DEBUG] iteration={i + 1} parsed_tool_calls={calls}")

            if not calls:
                if getattr(self.config, "debug", False):
                    print("[DEBUG] no tool calls -> return")
                return text

            clean_text = self._strip_tool_markers(text)
            working.append(Message(role="assistant", content=clean_text))

            obs = []
            for tool_name, raw_params in calls:
                if getattr(self.config, "debug", False):
                    print(f"[DEBUG] executing tool={tool_name} params={raw_params!r}")
                result = self._exec_tool(tool_name, raw_params)
                if getattr(self.config, "debug", False):
                    print(f"[DEBUG] tool_result tool={tool_name} -> {result!r}")
                obs.append(f"[{tool_name}] {result}")

            observation = "\n".join(obs)
            working.append(
                Message(
                    role="user",
                    content=f"工具执行结果:\n{observation}\n\n请基于这些结果给出最终回答。",
                )
            )

        if getattr(self.config, "debug", False):
            print("[DEBUG] max_tool_iterations reached -> final llm.invoke")
        return self.llm.invoke(working, **kwargs)

    def _parse_tool_calls(self, text: str) -> list[tuple[str, str]]:
        matches = _TOOL_CALL_PATTERN.findall(text or "")
        return [(name.strip(), params.strip()) for name, params in matches]

    def _strip_tool_markers(self, text: str) -> str:
        return _TOOL_CALL_PATTERN.sub("", text or "").strip()

    def _exec_tool(self, tool_name: str, raw_params: str) -> str:
        if not self.tool_registry:
            return "工具系统未配置"

        try:
            params = raw_params.strip()

            # 1) JSON 参数：{"expression": "..."}
            if (params.startswith("{") and params.endswith("}")) or (params.startswith("[") and params.endswith("]")):
                obj = json.loads(params)

                # calculator 常见约定：{"expression": "..."}
                if tool_name == "calculator" and isinstance(obj, dict) and "expression" in obj:
                    return self.tool_registry.execute_tool(tool_name, obj["expression"])

                # 其他工具：如果 registry 支持 dict，就把 dict 传下去（视你实现而定）
                # 如果 registry 只支持字符串，就转成紧凑 JSON 字符串
                return self.tool_registry.execute_tool(tool_name, json.dumps(obj, ensure_ascii=False))

            # 2) 非 JSON：直接当成输入字符串
            return self.tool_registry.execute_tool(tool_name, params)

        except Exception as e:
            return f"工具执行失败: {e}"

from __future__ import annotations

from dataclasses import dataclass
from typing import Any, Callable, Dict, Optional


@dataclass
class FunctionTool:
    name: str
    description: str
    func: Callable[[str], str]


class ToolRegistry:
    """
    最小可用 ToolRegistry：
    - register_function：注册一个 “字符串输入 -> 字符串输出” 的函数工具
    - execute_tool：执行工具
    - get_tools_description：生成用于提示词的工具说明（可选但常用）
    """

    def __init__(self) -> None:
        self._functions: Dict[str, FunctionTool] = {}

    def register_function(self, *, name: str, description: str, func: Callable[[str], str]) -> None:
        if not name:
            raise ValueError("tool name cannot be empty")
        if name in self._functions:
            # 教学阶段允许覆盖，工程阶段可以改为 raise
            pass
        self._functions[name] = FunctionTool(name=name, description=description, func=func)

    def get_tool(self, name: str) -> Optional[FunctionTool]:
        return self._functions.get(name)

    def list_tools(self) -> list[str]:
        return list(self._functions.keys())

    def get_tools_description(self) -> str:
        if not self._functions:
            return "暂无可用工具"
        lines = []
        for t in self._functions.values():
            lines.append(f"- {t.name}: {t.description}")
        return "\n".join(lines)

    def execute_tool(self, name: str, input_str: str) -> str:
        tool = self.get_tool(name)
        if tool is None:
            raise KeyError(f"tool not found: {name}")
        return tool.func(input_str)

6.12 ReActAgent 的框架化实现

ReAct 的核心贡献是：它把“推理轨迹”与“工具行动”显式化，并通过循环结构让智能体能够分步获得外部信息、逐步逼近答案。

框架化 ReAct 的关键，不是把 prompt 写得更长，而是把三个点做稳定：

  • 第一，输出格式必须可解析。
  • 第二，工具调用必须被 ToolRegistry 统一承接。
  • 第三，循环必须可控，可停止。

6.12.1 核心对象与主流程

ReAct 持续处理的核心对象是“执行历史（Thought/Action/Observation）”。它与对话历史不同，它是范式内部的过程状态，用于下一轮决策。

主流程可以被描述为：构造 ReAct 提示词（包含工具列表与执行历史）→ 调用模型 → 解析 Action → 若 Finish 则结束 → 否则执行工具得到 Observation → 写入执行历史 → 进入下一轮。

6.12.2 实现

# HelloAgents/agents/react_agent.py
from __future__ import annotations

import re
from dataclasses import dataclass
from typing import Optional, Sequence, List, Tuple

from HelloAgents.core.agent import Agent
from HelloAgents.core.message import Message
from HelloAgents.tools.registry import ToolRegistry


@dataclass
class ReActStep:
    thought: str
    action: str
    observation: Optional[str] = None


_ACTION_TOOL_PATTERN = re.compile(r"^([A-Za-z0-9_\-]+)\[(.*)\]$", re.S)
_ACTION_FINISH_PATTERN = re.compile(r"^Finish\[(.*)\]$", re.S)


DEFAULT_REACT_PROMPT = """你是一个具备推理与行动能力的AI助手。你需要通过“思考-行动-观察”的循环来解决问题。

可用工具如下（工具名与功能说明）：
{tools}

输出格式必须严格遵循（每次只做一个动作）：

Thought: <你对下一步要做什么的思考>
Action: <选择以下两种之一>
- <tool_name>[<tool_input>]     调用工具
- Finish[<final_answer>]       输出最终答案并结束

重要规则：
- 当需要外部信息、计算或检索时，必须使用工具，不允许臆测。
- 工具调用必须使用 tool_name[...] 格式，tool_input 尽量简洁。
- 只有在你确信已经得到足够信息后，才使用 Finish[...]。

问题：
{question}

已执行轨迹（供参考）：
{trace}

现在开始：
"""


class ReActAgent(Agent):
    """
    ReActAgent：用 Thought/Action/Observation 驱动的工具推理循环。
    """

    def __init__(
        self,
        *,
        name: str,
        llm,
        tool_registry: ToolRegistry,
        system_prompt: Optional[str] = None,
        config=None,
        max_steps: int = 6,
        prompt_template: str = DEFAULT_REACT_PROMPT,
    ):
        super().__init__(name=name, llm=llm, system_prompt=system_prompt, config=config)
        self.tool_registry = tool_registry
        self.max_steps = max_steps
        self.prompt_template = prompt_template

        self._steps: List[ReActStep] = []

    def _execute(self, *, messages: Sequence[Message], **kwargs) -> str:
        """
        约定：messages 由 Agent.run() 负责组装（system + history + user input）。
        ReActAgent 在 _execute 内部用循环驱动工具推理。
        """
        # 本次运行的“问题”通常是 messages 的最后一条 user
        question = self._extract_latest_user_input(messages)
        self._steps = []

        for i in range(self.max_steps):
            prompt = self._build_react_prompt(question)

            # 注意：这里使用“单轮 user prompt”，避免把 system/history 再嵌套一遍导致提示膨胀
            # 如需保留 system_prompt，可在 prompt_template 内表达角色约束（或把 system_prompt 拼到 prompt 顶部）
            react_messages = []
            if self.system_prompt:
                react_messages.append(Message(role="system", content=self.system_prompt))
            react_messages.append(Message(role="user", content=prompt))

            if getattr(self.config, "debug", False):
                print(f"[DEBUG] {self.name} - react step={i+1} prompt assembled")
                print(self._compact_trace_preview())

            raw = self.llm.invoke(list(react_messages), **kwargs)
            thought, action = self._parse_thought_action(raw)

            if getattr(self.config, "debug", False):
                print(f"[DEBUG] parsed thought={thought!r}")
                print(f"[DEBUG] parsed action={action!r}")

            # Finish
            m_finish = _ACTION_FINISH_PATTERN.match(action.strip())
            if m_finish:
                final_answer = m_finish.group(1).strip()
                return final_answer

            # Tool call: tool_name[tool_input]
            tool_name, tool_input = self._parse_tool_action(action)
            observation = self._exec_tool(tool_name, tool_input)

            if getattr(self.config, "debug", False):
                print(f"[DEBUG] executing tool={tool_name} input={tool_input!r}")
                print(f"[DEBUG] observation={observation!r}")

            self._steps.append(ReActStep(thought=thought, action=action, observation=observation))

        # 超出步数：给一个可解释的收敛输出
        return "抱歉，我在限定步数内仍未能完成任务。你可以提供更多信息，或允许我使用更多步骤。"

    def _extract_latest_user_input(self, messages: Sequence[Message]) -> str:
        for m in reversed(list(messages)):
            if getattr(m, "role", None) == "user":
                return getattr(m, "content", "")
        return ""

    def _build_react_prompt(self, question: str) -> str:
        tools = self.tool_registry.get_tools_description() if self.tool_registry else "暂无可用工具"
        trace = self._format_trace()
        return self.prompt_template.format(tools=tools, question=question, trace=trace)

    def _format_trace(self) -> str:
        if not self._steps:
            return "(空)"
        lines: List[str] = []
        for idx, s in enumerate(self._steps, 1):
            lines.append(f"Step {idx}")
            lines.append(f"Thought: {s.thought}")
            lines.append(f"Action: {s.action}")
            lines.append(f"Observation: {s.observation}")
            lines.append("")  # blank line
        return "\n".join(lines).strip()

    def _parse_thought_action(self, text: str) -> Tuple[str, str]:
        """
        解析模型输出中的 Thought 与 Action。
        要求模型严格输出两行，但这里做容错：允许额外文本，只要能提取到 Thought/Action 即可。
        """
        raw = (text or "").strip()

        # 常见形式：
        # Thought: ...
        # Action: ...
        thought = ""
        action = ""

        for line in raw.splitlines():
            if line.startswith("Thought:"):
                thought = line[len("Thought:"):].strip()
            elif line.startswith("Action:"):
                action = line[len("Action:"):].strip()

        # 兜底：如果模型把 Thought/Action 写成块状
        if not action:
            m = re.search(r"Action:\s*(.+)$", raw, re.M)
            if m:
                action = m.group(1).strip()
        if not thought:
            m = re.search(r"Thought:\s*(.+)$", raw, re.M)
            if m:
                thought = m.group(1).strip()

        if not action:
            # 解析失败时，强制让它 Finish（避免死循环）
            action = "Finish[我无法解析出有效的Action，请检查提示词约束或模型输出格式。]"
        return thought, action

    def _parse_tool_action(self, action: str) -> Tuple[str, str]:
        m = _ACTION_TOOL_PATTERN.match(action.strip())
        if not m:
            return "unknown_tool", action.strip()
        return m.group(1).strip(), m.group(2).strip()

    def _exec_tool(self, tool_name: str, tool_input: str) -> str:
        if not self.tool_registry:
            return "工具系统未配置"
        try:
            return self.tool_registry.execute_tool(tool_name, tool_input)
        except Exception as e:
            return f"工具执行失败: {e}"

    def _compact_trace_preview(self) -> str:
        # 仅用于 debug 时快速预览
        if not self._steps:
            return "[DEBUG] trace: (empty)"
        last = self._steps[-1]
        return f"[DEBUG] trace last: thought={last.thought[:60]!r} action={last.action[:60]!r}"

6.13 ReflectionAgent 的框架化实现

Reflection 的价值在于：它把一次性生成，变成可控迭代。对工程与教学而言，它非常适合用来做“输出质量提升”与“自我审阅”，例如写作、总结、方案设计、代码改写等任务。

框架化 Reflection 的关键是：定义清晰的迭代协议，并设置提前终止条件，否则系统很容易陷入“写了很多但没变好”的空转。

6.13.1 核心对象与主流程

Reflection 持续处理的核心对象是“候选答案版本”。主流程是：生成初稿 → 反思审阅 → 根据反馈改写 → 判断是否继续。

这里建议把提前终止条件设计成两类：

一种是语义终止：反思阶段返回“无需改进”。 另一种是量化终止：引入质量评分，分数达到阈值就停止。

6.13.2 代码实现

下面是一个友好、结构清晰的 ReflectionAgent。它展示了反思循环如何变得可控。 ReflectionAgent 解决的不是“更会写”，而是“更可控地变好”： - 核心对象：一次任务的版本产物（draft / attempt） 与其 反馈（feedback） - 主流程：initial → reflect → refine 循环，直到满足停止条件 - 停止条件： 1. 反馈判定“无需改进”；或 2. 达到最大迭代次数；或 3. （可选）达到质量阈值（评分机制）

        "回答:\n{draft}\n\n"
        "评分标准：准确性、完整性、可读性、可执行性。"

class ReflectionAgent(Agent):
    def __init__(
        self,
        *,
        name: str,
        llm,
        system_prompt: Optional[str] = None,
        config=None,
        prompts: Optional[ReflectionPrompts] = None,
        max_rounds: int = 2,
        enable_scoring: bool = False,
        score_threshold: float = 8.5,
        verbose: bool = False,
        trace_mode: str = "summary",   # "summary" | "full"
        trace_max_chars: int = 400,    # full 模式下也可截断，避免刷屏
    ):
        super().__init__(name=name, llm=llm, system_prompt=system_prompt, config=config)
        self.prompts = prompts or ReflectionPrompts()
        self.max_rounds = max_rounds
        self.enable_scoring = enable_scoring
        self.score_threshold = score_threshold

        self.verbose = verbose
        self.trace_mode = trace_mode
        self.trace_max_chars = trace_max_chars

    def _trace(self, title: str, content: str = "") -> None:
        if not self.verbose:
            return

        if self.trace_mode == "summary":
            if content:
                print(f"[TRACE] {self.name} - {title}: len={len(content)}")
            else:
                print(f"[TRACE] {self.name} - {title}")
            return

        # full 模式
        if not content:
            print(f"[TRACE] {self.name} - {title}")
            return

        snippet = content
        if self.trace_max_chars is not None and len(snippet) > self.trace_max_chars:
            snippet = snippet[: self.trace_max_chars] + " ...<truncated>..."
        print(f"[TRACE] {self.name} - {title}\n{snippet}\n")

    def _execute(self, *, messages: Sequence[Message], **kwargs) -> str:
        if not messages:
            return ""

        task = messages[-1].content
        base_context = list(messages[:-1])

        self._trace("task", task)

        draft = self._call_initial(base_context, task, **kwargs)
        self._trace("initial_draft", draft)

        if self.enable_scoring:
            score = self._call_score(base_context, task, draft, **kwargs)
            self._trace("score_after_initial", str(score))
            if score is not None and score >= self.score_threshold:
                self._trace("stop_reason", f"score >= {self.score_threshold}")
                return draft

        for r in range(1, self.max_rounds + 1):
            feedback = self._call_reflect(base_context, task, draft, **kwargs)
            self._trace(f"round_{r}_feedback", feedback)

            if self._is_no_improvement(feedback):
                self._trace("stop_reason", "no_improvement")
                return draft

            draft = self._call_refine(base_context, task, draft, feedback, **kwargs)
            self._trace(f"round_{r}_refined_draft", draft)

            if self.enable_scoring:
                score = self._call_score(base_context, task, draft, **kwargs)
                self._trace(f"round_{r}_score", str(score))
                if score is not None and score >= self.score_threshold:
                    self._trace("stop_reason", f"score >= {self.score_threshold}")
                    return draft

        self._trace("stop_reason", "max_rounds_reached")
        return draft

    def _call_initial(self, base_context: List[Message], task: str, **kwargs) -> str:
        prompt = self.prompts.initial.format(task=task)
        working = base_context + [Message(role="user", content=prompt)]
        return self.llm.invoke(working, **kwargs)

    def _call_reflect(self, base_context: List[Message], task: str, draft: str, **kwargs) -> str:
        prompt = self.prompts.reflect.format(task=task, draft=draft)
        working = base_context + [Message(role="user", content=prompt)]
        return self.llm.invoke(working, **kwargs)

    def _call_refine(self, base_context: List[Message], task: str, draft: str, feedback: str, **kwargs) -> str:
        prompt = self.prompts.refine.format(task=task, draft=draft, feedback=feedback)
        working = base_context + [Message(role="user", content=prompt)]
        return self.llm.invoke(working, **kwargs)

    def _call_score(self, base_context: List[Message], task: str, draft: str, **kwargs) -> Optional[float]:
        prompt = self.prompts.score.format(task=task, draft=draft)
        working = base_context + [Message(role="user", content=prompt)]
        text = (self.llm.invoke(working, **kwargs) or "").strip()
        try:
            return float(text.split()[0])
        except Exception:
            return None

    def _is_no_improvement(self, feedback: str) -> bool:
        return bool(feedback) and ("无需改进" in feedback)

6.14 Plan-and-Solve 的框架化实现

Plan-and-Solve 解决的是另一类工程问题：当任务复杂、步骤多、需要稳定顺序时，自由生成往往会漂移。Plan-and-Solve 把复杂任务拆成计划列表，再逐步求解，降低单步复杂度，也提升可控性。

框架化 Plan-and-Solve 的关键是：计划必须可解析。只要计划不可解析，后续执行就会退化为自由文本，失去范式意义。

6.14.1 核心对象与主流程

此范式持续处理的核心对象是“计划（Plan）”。

主流程是：生成计划（结构化列表）→ 解析计划 → 逐步执行（每步产出结果写入历史）→ 汇总输出。

6.14.2 代码实现

Planner 强制输出 Python list；Executor 只解决“当前步骤”；Finalizer 负责最终汇总。

# HelloAgents/agents/plan_solve_agent.py
from __future__ import annotations

import ast
import re
from dataclasses import dataclass
from typing import Optional, Sequence, List, Tuple

from HelloAgents.core.agent import Agent
from HelloAgents.core.message import Message
from HelloAgents.tools.registry import ToolRegistry


_TOOL_CALL_PATTERN = re.compile(r"\[TOOL_CALL:([^:]+):([^\]]+)\]")


@dataclass
class PlanSolvePrompts:
    planner: str = (
        "你是顶级规划专家。请把用户问题拆解为可执行的步骤计划。\n"
        "要求：输出必须是 Python 列表（list[str]），且只输出该列表，不要输出任何解释。\n\n"
        "问题:\n{task}\n\n"
        "输出示例:\n"
        '["步骤1", "步骤2", "步骤3"]\n'
    )

    executor: str = (
        "你是顶级执行专家。你将收到原始问题、完整计划、已完成步骤历史、以及当前步骤。\n"
        "要求：只解决“当前步骤”，输出该步骤的最终结果；不要输出计划，不要输出多余解释。\n\n"
        "原始问题:\n{task}\n\n"
        "完整计划:\n{plan}\n\n"
        "已完成步骤与结果:\n{history}\n\n"
        "当前步骤:\n{current_step}\n"
    )

    finalizer: str = (
        "你是严谨的总结者。请基于计划与步骤结果，给出最终答案。\n"
        "要求：最终答案必须直接回答原始问题，不要复述计划，不要输出步骤编号。\n\n"
        "原始问题:\n{task}\n\n"
        "完整计划:\n{plan}\n\n"
        "步骤执行历史:\n{history}\n\n"
        "请输出最终答案："
    )
class PlanAndSolveAgent(Agent):
    """
    Plan-and-Solve：规划 -> 分步执行 -> 汇总
    可选：分步执行阶段支持工具调用（TOOL_CALL 标记）
    """

    def __init__(
        self,
        *,
        name: str,
        llm,
        system_prompt: Optional[str] = None,
        config=None,
        prompts: Optional[PlanSolvePrompts] = None,
        max_plan_steps: int = 8,
        tool_registry: Optional[ToolRegistry] = None,
        enable_tool_calling: bool = True,
        max_tool_iterations: int = 3,
        planner_kwargs: Optional[dict] = None,
        executor_kwargs: Optional[dict] = None,
        finalizer_kwargs: Optional[dict] = None,
        verbose: bool = False,
    ):
        super().__init__(name=name, llm=llm, system_prompt=system_prompt, config=config)
        self.prompts = prompts or PlanSolvePrompts()
        self.max_plan_steps = max_plan_steps

        self.tool_registry = tool_registry
        self.enable_tool_calling = enable_tool_calling and tool_registry is not None
        self.max_tool_iterations = max_tool_iterations

        self.planner_kwargs = planner_kwargs or {}
        self.executor_kwargs = executor_kwargs or {}
        self.finalizer_kwargs = finalizer_kwargs or {}
        self.verbose = verbose

    def _execute(self, *, messages: Sequence[Message], **kwargs) -> str:
        if not messages:
            return ""

        task = messages[-1].content
        base_context = list(messages[:-1])  # system + history（如果 Agent.run 注入了的话）

        plan = self._make_plan(base_context, task)
        plan = plan[: self.max_plan_steps]

        step_history: List[Tuple[str, str]] = []
        for step in plan:
            result = self._run_step(base_context, task, plan, step_history, step)
            step_history.append((step, result))

        final = self._finalize(base_context, task, plan, step_history)

        return final

    def _make_plan(self, base_context: List[Message], task: str) -> List[str]:
        prompt = self.prompts.planner.format(task=task)
        text = self.llm.invoke(base_context + [Message(role="user", content=prompt)], **self.planner_kwargs)
        if self.verbose:
            print(f"[DEBUG] planner_raw={text!r}")
        plan = self._parse_plan(text)

        # 自愈：如果解析失败，再强制模型只输出列表
        if not plan:
            repair = (
                "你刚才的输出无法被解析为 Python 列表。\n"
                "请只输出一个 Python 列表（list[str]），不要输出任何解释或代码块。\n\n"
                f"问题:\n{task}\n"
            )
            text2 = self.llm.invoke(base_context + [Message(role="user", content=repair)], **self.planner_kwargs)
            plan = self._parse_plan(text2)

        return plan or ["给出直接答案（无法生成可靠计划，改为直接求解）"]

    def _parse_plan(self, text: str) -> List[str]:
        if not text:
            return []
        cleaned = text.strip()

        # 允许模型把列表包在 ```python ... ``` 里时也能解析
        cleaned = cleaned.replace("```python", "").replace("```", "").strip()

        try:
            obj = ast.literal_eval(cleaned)
            if not isinstance(obj, list):
                return []
            plan = []
            for x in obj:
                if isinstance(x, str) and x.strip():
                    plan.append(x.strip())
            return plan
        except Exception:
            return []

    def _run_step(
        self,
        base_context: List[Message],
        task: str,
        plan: List[str],
        step_history: List[Tuple[str, str]],
        current_step: str,
    ) -> str:
        if self.verbose:
            print(f"[DEBUG] step_start: {current_step}")
        history_text = self._format_step_history(step_history)
        plan_text = self._format_plan(plan)

        prompt = self.prompts.executor.format(
            task=task,
            plan=plan_text,
            history=history_text,
            current_step=current_step,
        )

        if not self.enable_tool_calling:
            return self.llm.invoke(base_context + [Message(role="user", content=prompt)], **self.executor_kwargs)

        # 工具增强执行：模型 -> 解析工具 -> 执行 -> 注入 observation -> 再问模型
        working = base_context + [Message(role="user", content=self._executor_prompt_with_tools(prompt))]

        for t in range(self.max_tool_iterations):
            text = self.llm.invoke(working, **self.executor_kwargs)
            calls = self._parse_tool_calls(text)

            if not calls:
                return text.strip()

            clean_text = self._strip_tool_markers(text)
            if clean_text:
                working.append(Message(role="assistant", content=clean_text))

            obs_lines = []
            for tool_name, raw_params in calls:
                if self.verbose:
                    print(f"[DEBUG] step_tool_iteration={t} calls={calls}")
                obs_lines.append(f"[{tool_name}] {self._exec_tool(tool_name, raw_params)}")

            observation = "\n".join(obs_lines)
            working.append(
                Message(
                    role="user",
                    content=f"工具执行结果:\n{observation}\n\n请基于工具结果，输出该步骤的最终结果。",
                )
            )

        return self.llm.invoke(working, **self.executor_kwargs).strip()

    def _finalize(
        self,
        base_context: List[Message],
        task: str,
        plan: List[str],
        step_history: List[Tuple[str, str]],
    ) -> str:
        prompt = self.prompts.finalizer.format(
            task=task,
            plan=self._format_plan(plan),
            history=self._format_step_history(step_history),
        )
        return self.llm.invoke(base_context + [Message(role="user", content=prompt)], **self.finalizer_kwargs).strip()

    def _format_plan(self, plan: List[str]) -> str:
        return "\n".join([f"- {s}" for s in plan])

    def _format_step_history(self, step_history: List[Tuple[str, str]]) -> str:
        if not step_history:
            return "(无)"
        parts = []
        for i, (step, result) in enumerate(step_history, 1):
            parts.append(f"Step {i}: {step}\nResult: {result}")
        return "\n\n".join(parts)

    def _executor_prompt_with_tools(self, base_prompt: str) -> str:
        if not self.tool_registry:
            return base_prompt

        tools_desc = self.tool_registry.get_tools_description()
        tool_rules = (
            "\n\n你可以使用工具来获得准确结果。工具调用必须严格使用以下格式：\n"
            "[TOOL_CALL:<tool_name>:<params>]\n"
            "规则：\n"
            "- 当问题需要计算、查询、检索或外部信息时，优先调用工具。\n"
            "- 如果你输出了 TOOL_CALL，本条回复除 TOOL_CALL 外不要输出最终答案。\n"
            "- 工具执行结果会随后提供给你，你需要基于结果完成本步骤。\n"
        )
        return f"{base_prompt}\n\n可用工具:\n{tools_desc}{tool_rules}"

    def _parse_tool_calls(self, text: str) -> list[tuple[str, str]]:
        matches = _TOOL_CALL_PATTERN.findall(text or "")
        return [(name.strip(), params.strip()) for name, params in matches]

    def _strip_tool_markers(self, text: str) -> str:
        return _TOOL_CALL_PATTERN.sub("", text or "").strip()

    def _exec_tool(self, tool_name: str, raw_params: str) -> str:
        if not self.tool_registry:
            return "工具系统未配置"
        try:
            return self.tool_registry.execute_tool(tool_name, raw_params)
        except Exception as e:
            return f"工具执行失败: {e}"

# HelloAgents/tools/base.py
from __future__ import annotations

from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import Any, Dict, List


@dataclass
class ToolParameter:
    name: str
    type: str  # "string" | "number" | "boolean" | "object" | "array"
    description: str
    required: bool = True
    default: Any = None


class Tool(ABC):
    """所有工具的统一接口：run(parameters) -> str"""

    def __init__(self, name: str, description: str):
        self.name = name
        self.description = description

    @abstractmethod
    def run(self, parameters: Dict[str, Any]) -> str:
        raise NotImplementedError

    @abstractmethod
    def get_parameters(self) -> List[ToolParameter]:
        raise NotImplementedError

# HelloAgents/tools/registry.py
from __future__ import annotations

import json
from typing import Any, Callable, Dict, Optional

from HelloAgents.tools.base import Tool


class ToolRegistry:
    """
    统一的工具注册表。
    - register_tool(Tool): 复杂工具（结构化参数）
    - register_function(name, description, func): 简单工具（str -> str）
    - execute_tool(name, raw_params): 统一执行入口
    """

    def __init__(self):
        self._tools: Dict[str, Tool] = {}
        self._functions: Dict[str, Dict[str, Any]] = {}

    def register_tool(self, tool: Tool) -> None:
        if tool.name in self._tools or tool.name in self._functions:
            print(f"⚠️ 警告:工具 '{tool.name}' 已存在，将被覆盖。")
        self._tools[tool.name] = tool
        print(f"✅ 工具 '{tool.name}' 已注册(Tool)。")

    def register_function(self, name: str, description: str, func: Callable[[str], str]) -> None:
        if name in self._tools or name in self._functions:
            print(f"⚠️ 警告:工具 '{name}' 已存在，将被覆盖。")
        self._functions[name] = {"description": description, "func": func}
        print(f"✅ 工具 '{name}' 已注册(Function)。")

    def get_tool(self, name: str) -> Optional[Tool]:
        return self._tools.get(name)

    def list_tools(self) -> list[str]:
        return sorted(set(list(self._tools.keys()) + list(self._functions.keys())))

    def get_tools_description(self) -> str:
        lines = []
        for t in self._tools.values():
            lines.append(f"- {t.name}: {t.description}")
        for name, info in self._functions.items():
            lines.append(f"- {name}: {info['description']}")
        return "\n".join(lines) if lines else "暂无可用工具"

    def execute_tool(self, name: str, raw_params: str) -> str:
        """
        raw_params 兼容两种形态：
        1) JSON 字符串：{"expression": "2+2"} / {"text":"...","pattern":"..."}
        2) 普通字符串：直接作为 input
        """
        if name in self._tools:
            tool = self._tools[name]
            params = self._parse_raw_params(raw_params)
            return tool.run(params)

        if name in self._functions:
            func = self._functions[name]["func"]
            # function 工具就吃纯字符串
            return str(func(raw_params))

        raise KeyError(f"未找到工具: {name}")

    def _parse_raw_params(self, raw: str) -> Dict[str, Any]:
        raw = (raw or "").strip()
        if not raw:
            return {"input": ""}

        # 优先尝试 JSON
        if (raw.startswith("{") and raw.endswith("}")) or (raw.startswith("[") and raw.endswith("]")):
            try:
                obj = json.loads(raw)
                if isinstance(obj, dict):
                    return obj
                # 如果是 list，就包一层
                return {"input": obj}
            except Exception:
                # 解析失败就当普通字符串
                return {"input": raw}

        return {"input": raw}

# HelloAgents/tools/builtin/calculator.py
from __future__ import annotations

import ast
import math
import operator
from typing import Any, Dict, List

from HelloAgents.tools.base import Tool, ToolParameter


class CalculatorTool(Tool):
    """
    安全计算器：
    - 支持 + - * / ** ( ) 以及常量 pi, e
    - 支持函数: sqrt, sin, cos, tan, log
    输入参数支持：
    - {"expression": "..."}
    - {"input": "..."}  # 兼容 ToolRegistry 的字符串模式
    """

    def __init__(self):
        super().__init__(name="calculator", description="安全数学计算工具，输入 expression 返回计算结果。")

    def get_parameters(self) -> List[ToolParameter]:
        return [
            ToolParameter(name="expression", type="string", description="数学表达式，如 '2 + 3 * 4'。", required=False),
            ToolParameter(name="input", type="string", description="表达式的别名输入(兼容模式)。", required=False),
        ]

    def run(self, parameters: Dict[str, Any]) -> str:
        expr = (parameters.get("expression") or parameters.get("input") or "").strip()
        if not expr:
            return "错误：expression 不能为空"

        try:
            value = self._safe_eval(expr)
            # 统一字符串输出，便于模型消费
            return str(value)
        except Exception as e:
            return f"计算失败：{e}"

    def _safe_eval(self, expr: str) -> Any:
        allowed_binops = {
            ast.Add: operator.add,
            ast.Sub: operator.sub,
            ast.Mult: operator.mul,
            ast.Div: operator.truediv,
            ast.Pow: operator.pow,
            ast.Mod: operator.mod,
        }
        allowed_unary = {
            ast.UAdd: operator.pos,
            ast.USub: operator.neg,
        }
        allowed_names = {
            "pi": math.pi,
            "e": math.e,
        }
        allowed_funcs = {
            "sqrt": math.sqrt,
            "sin": math.sin,
            "cos": math.cos,
            "tan": math.tan,
            "log": math.log,
        }

        node = ast.parse(expr, mode="eval")

        def _eval(n):
            if isinstance(n, ast.Expression):
                return _eval(n.body)
            if isinstance(n, ast.Constant):  # py3.8+
                if isinstance(n.value, (int, float)):
                    return n.value
                raise ValueError("不支持的常量类型")
            if isinstance(n, ast.BinOp):
                op = allowed_binops.get(type(n.op))
                if not op:
                    raise ValueError("不支持的二元运算")
                return op(_eval(n.left), _eval(n.right))
            if isinstance(n, ast.UnaryOp):
                op = allowed_unary.get(type(n.op))
                if not op:
                    raise ValueError("不支持的一元运算")
                return op(_eval(n.operand))
            if isinstance(n, ast.Name):
                if n.id in allowed_names:
                    return allowed_names[n.id]
                raise ValueError(f"不支持的变量: {n.id}")
            if isinstance(n, ast.Call):
                if not isinstance(n.func, ast.Name):
                    raise ValueError("不支持的函数调用形式")
                fname = n.func.id
                if fname not in allowed_funcs:
                    raise ValueError(f"不支持的函数: {fname}")
                args = [_eval(a) for a in n.args]
                return allowed_funcs[fname](*args)

            raise ValueError("不支持的表达式结构")

        return _eval(node)

# HelloAgents/tools/builtin/datetime_tool.py
from __future__ import annotations

from datetime import datetime, timezone
from typing import Any, Dict, List

from HelloAgents.tools.base import Tool, ToolParameter


class DateTimeTool(Tool):
    """
    返回当前时间（UTC 或本地）
    输入：
    - {"tz": "utc"} / {"tz": "local"}
    - {"format": "%Y-%m-%d %H:%M:%S"}
    """

    def __init__(self):
        super().__init__(name="now", description="获取当前时间。支持 tz=utc/local 与 format 自定义格式。")

    def get_parameters(self) -> List[ToolParameter]:
        return [
            ToolParameter(name="tz", type="string", description="时区: utc 或 local", required=False, default="local"),
            ToolParameter(name="format", type="string", description="时间格式化字符串", required=False, default="%Y-%m-%d %H:%M:%S"),
        ]

    def run(self, parameters: Dict[str, Any]) -> str:
        tz = (parameters.get("tz") or "local").strip().lower()
        fmt = parameters.get("format") or "%Y-%m-%d %H:%M:%S"

        if tz == "utc":
            dt = datetime.now(timezone.utc)
        else:
            dt = datetime.now()

        try:
            return dt.strftime(fmt)
        except Exception as e:
            return f"时间格式化失败：{e}"
