8  Context Engineering

8.1 上下文工程：构建智能的上下文配置系统

在经历了数年提示工程（Prompt Engineering）成为应用型AI的焦点之后，一个新的术语开始走到台前：上下文工程（Context Engineering）。如今，用语言模型构建系统不再只是找对提示词里的句式和措辞，而是要回答一个更宏观的问题：什么样的上下文配置，最有可能让模型产出我们期望的行为？

本章将深入探讨上下文工程的核心概念、设计原理和实践方法。我们将学习如何在 HelloAgents 框架中构建智能的上下文管理系统，包括上下文的分类、管理、优化和压缩等核心能力。

8.2 上下文工程：从提示工程到上下文工程

8.2.1 提示工程的局限性

在上下文工程兴起之前，提示工程是优化大语言模型输出的主要手段。然而，提示工程存在以下局限：

1. 局限于单次优化

提示工程通常关注单次提示的优化，难以系统性地考虑多轮对话中的上下文积累问题。

2. 忽视上下文多样性

提示工程往往只关注提示词本身，而忽略了不同类型上下文（系统提示、知识、记忆、历史对话）的有机组合。

3. 静态优化

提示工程通常是静态的，难以根据查询和目标动态调整上下文配置。

4. 缺乏系统性框架

提示工程缺乏统一的框架来管理和优化整个上下文系统。

8.2.2 上下文工程的核心理念

上下文工程超越了提示工程的局限，它关注的是：

核心问题：什么样的上下文配置，最有可能让模型产出我们期望的行为？

上下文配置包括： - 系统提示 - 知识库上下文 - 记忆上下文 - 指令上下文 - 对话历史 - 工具调用结果 - 检索增强内容

上下文工程的关键： - 上下文分类：不同类型的上下文有不同的特点和用途 - 上下文管理：统一管理和调度所有上下文 - 上下文优化：根据查询和目标智能优化上下文 - 上下文压缩：在限制内最大化信息密度

8.3 HelloAgents 框架中的上下文工程实现

基于上下文工程的核心理念，HelloAgents 框架实现了一套完整的上下文管理系统。

8.3.1 上下文工程架构

上下文工程架构
├── 基础设施层 (Infrastructure Layer)
│   ├── ContextConfig - 配置管理
│   ├── ContextItem - 上下文数据结构
│   └── ContextRole - 上下文角色枚举
├── 管理层 (Management Layer)
│   └── ContextManager - 上下文管理器
├── 处理层 (Processing Layer)
│   ├── ContextCompressor - 上下文压缩器
│   └── ContextOptimizer - 上下文优化器
└── 应用层 (Application Layer)
    └── ContextEnhancedAgent - 上下文增强 Agent

8.3.2 核心数据结构

8.3.2.1 ContextRole - 上下文角色

class ContextRole(str, Enum):
    """上下文角色"""
    SYSTEM = "system"              # 系统提示
    USER = "user"                  # 用户输入
    ASSISTANT = "assistant"          # 助手回复
    TOOL = "tool"                    # 工具调用
    MEMORY = "memory"                # 记忆上下文
    KNOWLEDGE = "knowledge"          # 知识上下文
    INSTRUCTION = "instruction"      # 指令上下文

设计思路： - 细粒度分类：区分不同类型的上下文，便于精细化管理 - 优先级设计：不同角色有不同的默认优先级 - 扩展性：易于添加新的角色类型

8.3.2.2 ContextConfig - 上下文配置

@dataclass
class ContextConfig:
    """
    上下文配置
    """
    # 上下文大小限制
    max_context_length: int = 8000
    max_system_prompt_length: int = 2000
    max_memory_context_length: int = 1000
    max_knowledge_context_length: int = 2000

    # 上下文策略
    compression_strategy: str = "importance"  # 压缩策略
    selection_strategy: str = "relevance"     # 选择策略
    ordering_strategy: str = "chronological"  # 排序策略

    # 优先级权重
    system_prompt_priority: float = 1.0
    memory_priority: float = 0.7
    knowledge_priority: float = 0.8
    instruction_priority: float = 0.9

设计思路： - 可配置性：所有关键参数都可配置 - 默认值：提供合理的默认配置 - 策略支持：支持多种压缩、选择和排序策略

8.3.2.3 ContextItem - 上下文项

@dataclass(frozen=True)
class ContextItem:
    """
    上下文项
    """
    content: str                      # 上下文内容
    role: ContextRole                   # 角色
    importance: float = 0.5            # 重要性评分 (0.0-1.0)
    timestamp: datetime                # 时间戳
    metadata: Dict[str, Any]           # 扩展元数据

设计思路： - 不可变性：确保上下文项创建后不被意外修改 - 元数据丰富：支持携带额外的信息（来源、版本等） - 类型安全：使用类型注解确保数据一致性

8.3.3 上下文管理器

ContextManager 是上下文工程的核心，负责统一管理和调度所有上下文：

class ContextManager:
    """
    上下文管理器：统一管理和调度所有上下文

    功能：
    - 添加不同类型的上下文
    - 根据配置构建完整上下文
    - 支持多种排序和选择策略
    - 提供 OpenAI 格式转换（自动映射额外角色到标准角色）
    """

角色映射机制：

由于 HelloAgents 框架的 Message 类只支持标准 OpenAI 角色（system、user、assistant、tool），ContextManager 在转换上下文时会自动将额外角色映射到标准角色：

  • MEMORY → user：记忆作为用户历史对话的一部分
  • KNOWLEDGE → system：知识作为系统提供的事实信息
  • INSTRUCTION → system：指令作为系统行为指导

这种映射确保了上下文工程系统与 HelloAgents 框架的完美兼容。

8.3.3.1 添加上下文

manager = ContextManager()

# 添加系统提示
manager.add_system("你是一个专业的 Python 编程助手。", importance=1.0)

# 添加指令
manager.add_instruction("回答要简洁明了，先简后详。", importance=0.9)

# 添加知识
manager.add_knowledge("Python 是一种编程语言。", importance=0.8)

# 添加记忆
manager.add_memory("用户喜欢学习 Python。", importance=0.7)

8.3.3.2 构建上下文

# 构建完整的上下文
context = manager.build_context(
    query="Python 是什么？",
    include_system=True,
    include_memory=True,
    include_knowledge=True,
    include_instructions=True
)

# 自动转换为 OpenAI 格式
# messages 格式: [{"role": "...", "content": "..."}, ...]

重要提示：HelloAgents 框架的 Message 类只支持标准 OpenAI 角色。为了兼容框架，ContextManager 会自动将额外角色映射到标准角色：

role_mapping = {
    ContextRole.MEMORY: "user",        # 记忆映射为用户消息
    ContextRole.KNOWLEDGE: "system",    # 知识映射为系统消息
    ContextRole.INSTRUCTION: "system",  # 指令映射为系统消息
}

这样可以在保持上下文分类清晰的同时，与 HelloAgents 框架无缝集成。

8.3.3.3 上下文选择策略

基于优先级的选择：

系统提示 (1.0) > 指令 (0.9) > 知识 (0.8) > 记忆 (0.7)

基于相关性的排序：

使用关键词匹配计算上下文与查询的相关性，优先选择更相关的上下文。

基于时间的排序：

优先选择最近的上下文，确保信息的时效性。

8.4.3 3. 上下文压缩策略

当上下文超过限制时，使用智能压缩：

def build_messages(self, query: str):
    # 构建上下文
    contexts = self._get_all_contexts()
    
    # 检查是否需要压缩
    total_length = sum(ctx.length() for ctx in contexts)
    target_length = self.config.max_context_length
    
    if total_length > target_length:
        # 压缩上下文
        contexts = self.compressor.compress(
            contexts,
            target_length=target_length,
            strategy="importance"
        )
    
    # 转换为消息格式
    messages = [
        {
            "role": ctx.role.value,
            "content": ctx.content
        }
        for ctx in contexts
    ]
    
    return messages

8.4.4 4. 上下文质量监控

监控上下文的质量和效果：

def monitor_context_quality(self, query: str, response: str):
    """监控上下文质量"""
    # 获取改进建议
    suggestions = self.optimizer.suggest_improvements(
        contexts=self._get_all_contexts(),
        query=query,
        target_length=self.config.max_context_length
    )
    
    # 记录建议
    if not suggestions["is_optimal"]:
        self.context_manager.add_memory(
            f"上下文优化建议: {suggestions}",
            importance=0.6
        )
    
    return suggestions

8.5 上下文工程与记忆系统的协同

上下文工程和记忆系统可以协同工作，构建更智能的系统：

8.5.1 1. 记忆作为上下文

将记忆系统中的记忆项转换为上下文：

def add_memory_to_context(self, memories: List[MemoryItem]):
    """将记忆添加到上下文"""
    for memory in memories:
        self.context_manager.add_memory(
            content=memory.content,
            importance=memory.importance
        )

8.5.2 2. 检索增强上下文

使用 RAG 系统检索知识，添加到上下文：

def add_knowledge_to_context(self, query: str, rag_system):
    """检索知识并添加到上下文"""
    retrieval_result, _ = rag_system.query(query, top_k=3)
    
    for doc, similarity in retrieval_result:
        self.context_manager.add_knowledge(
            content=doc.content,
            importance=similarity,
            source=doc.metadata.get("source", "unknown")
        )

8.5.3 3. 上下文持久化

将重要的上下文持久化到记忆系统：

def persist_important_context(self):
    """将重要上下文持久化到记忆"""
    contexts = self.context_manager._get_all_contexts()
    
    for ctx in contexts:
        if ctx.importance >= 0.8:
            # 转换为记忆项
            memory_item = MemoryItem(
                content=ctx.content,
                memory_type=self._map_role_to_memory_type(ctx.role),
                importance=ctx.importance,
                metadata=ctx.metadata
            )
            
            # 添加到记忆系统
            self.memory_manager.add(
                content=memory_item.content,
                memory_type=memory_item.memory_type,
                importance=memory_item.importance
            )

8.6 实际应用案例

角色映射在实际应用中的应用：

在所有实际应用案例中，当构建上下文并调用 LLM 时，都需要将额外角色映射到标准 OpenAI 角色，以确保与 HelloAgents 框架的兼容性：

from HelloAgents.context import ContextRole

role_mapping = {

    ContextRole.KNOWLEDGE: "system",
    ContextRole.INSTRUCTION: "system",

8.6.1 案例 1：智能客服系统

构建一个能够记住客户历史并提供个性化服务的智能客服：

class CustomerServiceAgent:
    def __init__(self, llm, memory_manager, rag_system):
        self.context_manager = ContextManager()
        self.memory_manager = memory_manager
        self.rag_system = rag_system
        self.llm = llm
        
        # 设置系统提示
        self.context_manager.add_system(
            "你是一个专业的客服代表，擅长解决客户问题。",
            importance=1.0
        )
    
    def handle_inquiry(self, customer_id: str, inquiry: str):
        # 1. 从记忆中检索客户信息
        customer_info = self.memory_manager.search(
            query=f"客户 {customer_id}",
            memory_types=[MemoryType.EPISODIC, MemoryType.SEMANTIC],
            limit=5
        )
        
        # 2. 添加客户信息到上下文
        for mem in customer_info:
            self.context_manager.add_memory(
                content=mem.content,
                importance=mem.importance
            )
        
        # 3. 从知识库检索相关解决方案
        retrieval_result, _ = self.rag_system.query(inquiry, top_k=3)
        
        for doc, similarity in retrieval_result:
            self.context_manager.add_knowledge(
                content=doc.content,
                importance=similarity
            )
        
        # 4. 构建并优化上下文
        optimized_contexts = self.optimizer.optimize(
            contexts=self._get_all_contexts(),
            query=inquiry,
            target_length=4000,
            objective="accuracy"
        )
        
        # 5. 调用 LLM
        messages = self._to_messages(optimized_contexts)
        response = self.llm.invoke(messages)
        
        # 6. 记录对话
        self.memory_manager.add(
            content=f"客户 {customer_id} 询问: {inquiry}",
            memory_type=MemoryType.EPISODIC,
            importance=0.7
        )
        self.memory_manager.add(
            content=f"客服回复: {response}",
            memory_type=MemoryType.EPISODIC,
            importance=0.6
        )
        
        return response

            "根据学生的学习进度和偏好，提供个性化的学习建议。",
            importance=0.9
        )
    
    def answer_question(self, student_id: str, question: str):
        # 1. 从记忆中检索学习信息
        learning_info = self.memory_manager.search(
            query=f"学生 {student_id}",
            memory_types=[MemoryType.EPISODIC, MemoryType.SEMANTIC],
            limit=5
        )
        
        # 2. 添加学习信息到上下文
        for mem in learning_info:
            self.context_manager.add_memory(
                content=mem.content,
                importance=mem.importance
            )
        
        # 3. 从知识库检索相关知识点
        retrieval_result, _ = self.rag_system.query(question, top_k=3)
        
        for doc, similarity in retrieval_result:
            self.context_manager.add_knowledge(
                content=doc.content,
                importance=similarity
            )
        
        # 4. 构建上下文（优先多样性）
        optimized_contexts = self.optimizer.optimize(
            contexts=self._get_all_contexts(),
            query=question,
            target_length=4000,
            objective="diversity"
        )
        
        # 5. 调用 LLM
        messages = self._to_messages(optimized_contexts)
        response = self.llm.invoke(messages)
        
        # 6. 记录学习活动
        self.memory_manager.add(
            content=f"学生 {student_id} 提问: {question}",
            memory_type=MemoryType.EPISODIC,
            importance=0.8
        )
        
        return response

8.7 上下文工程的进阶技巧

8.7.1 1. 上下文分层

根据上下文的重要性进行分层管理：

class LayeredContextManager:
    """
    分层上下文管理器
    """
    def __init__(self):
        self.core_contexts = []      # 核心上下文（必须包含）
        self.optional_contexts = []  # 可选上下文（按需包含）
        self.background_contexts = []  # 背景上下文（低优先级）
    
    def build_context(self, query: str, max_length: int):
        """构建分层上下文"""
        contexts = []
        
        # 1. 核心上下文（必须包含）
        contexts.extend(self.core_contexts)
        
        # 2. 可选上下文（按需包含）
        remaining_length = max_length - sum(ctx.length() for ctx in contexts)
        for ctx in self.optional_contexts:
            if remaining_length >= ctx.length():
                contexts.append(ctx)
                remaining_length -= ctx.length()
        
        # 3. 背景上下文（空间允许时包含）
        for ctx in self.background_contexts:
            if remaining_length >= ctx.length():
                contexts.append(ctx)
                remaining_length -= ctx.length()
        
        return contexts

8.7.2 2. 上下文缓存

缓存常用的上下文配置，避免重复计算：

class ContextCache:
    """
    上下文缓存
    """
    def __init__(self, max_size: int = 100):
        self.cache = {}
        self.max_size = max_size
    
    def get(self, query: str, objective: str) -> Optional[List[ContextItem]]:
        """获取缓存的上下文"""
        key = f"{query}:{objective}"
        return self.cache.get(key)
    
    def set(self, query: str, objective: str, contexts: List[ContextItem]):
        """缓存上下文"""
        key = f"{query}:{objective}"
        
        # 如果缓存已满，删除最旧的项
        if len(self.cache) >= self.max_size:
            oldest_key = min(self.cache.keys(), 
                          key=lambda k: self.cache[k][0].timestamp)
            del self.cache[oldest_key]
        
        self.cache[key] = contexts

8.7.3 3. 上下文 A/B 测试

对不同的上下文配置进行 A/B 测试，找到最优配置：

class ContextABTester:
    """
    上下文 A/B 测试器
    """
    def test_configurations(
        self,
        queries: List[str],
        configs: List[ContextConfig],
        llm
    ) -> Dict[str, Any]:
        """测试不同的上下文配置"""
        results = {}
        
        for config in configs:
            config_key = f"{config.compression_strategy}_{config.ordering_strategy}"
            results[config_key] = {
                "config": config,
                "responses": [],
                "avg_length": 0,
                "avg_time": 0
            }
            
            for query in queries:
                # 使用该配置处理查询
                start_time = time.time()
                response = self._process_with_config(query, config, llm)
                end_time = time.time()
                
                results[config_key]["responses"].append(response)
                results[config_key]["avg_length"] += len(response)
                results[config_key]["avg_time"] += (end_time - start_time)
            
            # 计算平均值
            num_queries = len(queries)
            results[config_key]["avg_length"] /= num_queries
            results[config_key]["avg_time"] /= num_queries
        
        return results
    
    def _process_with_config(self, query: str, config: ContextConfig, llm) -> str:
        """使用指定配置处理查询"""
        # 创建临时管理器
        manager = ContextManager(config=config)
        
        # 添加基础上下文
        manager.add_system("你是一个 AI 助手。", importance=1.0)
        manager.add_knowledge("Python 是一种编程语言。", importance=0.8)
        
        # 构建上下文
        contexts = manager.build_context(query)
        
        # 调用 LLM
        messages = [
            {
                "role": ctx.role.value,
                "content": ctx.content
            }
            for ctx in contexts
        ]
        
        return llm.invoke(messages)
