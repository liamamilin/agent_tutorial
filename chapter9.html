9  Intelligent Agent Communication Protocol

9.1 智能体通信协议

在前面的章节中，我们构建了功能完备的单体智能体，它们具备推理、工具调用和记忆能力。然而，当我们尝试构建更复杂的 AI 系统时，自然会有疑问：如何让智能体与外部世界高效交互？如何让多个智能体相互协作？

这正是智能体通信协议要解决的核 心问题。本章将为 HelloAgents 框架引入三种通信协议：MCP（Model Context Protocol）用于智能体与工具的标准化通信，A2A（Agent-to-Agent Protocol）用于智能体间的点对点协作，ANP（Agent Network Protocol）用于构建大规模智能体网络。这三种协议共同构成了智能体通信的基础设施层。

9.2 通信协议的必要性

9.2.1 为什么需要通信协议？

在构建实际的 AI 应用时，我们面临以下挑战：

1. 工具调用的标准化

智能体需要调用各种外部工具和服务，但这些工具的接口各不相同。没有统一的协议，每次集成新工具都需要编写适配代码，增加了开发成本和维护难度。

2. 智能体间的协作

当多个智能体协同工作时，它们需要一种可靠的方式来交换信息、协调任务和共享状态。没有统一的协议，智能体之间的通信会变得混乱和不可靠。

3. 大规模网络管理

当我们需要构建包含数百甚至数千个智能体的网络时，如何管理网络拓扑、路由消息和协调行为变得极其复杂。没有统一的协议，网络管理将变得不可维护。

4. 系统的可扩展性

随着系统规模的增长，通信机制需要能够轻松扩展以支持更多的节点和更复杂的交互模式。没有统一的协议，系统扩展会变得困难。

9.2.2 HelloAgents 的解决方案

HelloAgents 框架通过三种互补的通信协议来解决这些问题：

通信协议层次结构
├── MCP (Model Context Protocol)
│   ├── 智能体 ↔ 工具的标准化通信
│   ├── 统一的请求-响应格式
│   └── 工具注册和发现机制
├── A2A (Agent-to-Agent Protocol)
│   ├── 智能体 ↔ 智能体的点对点通信
│   ├── 直接消息传递
│   ├── 请求-响应模式
│   └── 任务委托和协调
└── ANP (Agent Network Protocol)
    ├── 大规模智能体网络管理
    ├── 网络拓扑管理
    ├── 节点发现和路由
    └── 网络级协调和同步

9.3 MCP：智能体与工具的标准化通信

MCP（Model Context Protocol）是一种标准化的协议，用于智能体与工具之间的通信。它定义了统一的请求-响应格式、错误处理和消息类型，使得智能体可以轻松调用各种工具和服务。

9.3.1 MCP 的核心概念

9.3.1.1 消息类型

MCP 定义了多种消息类型，支持不同的通信场景：

class MCPMessageType(str, Enum):
    # 请求类型
    TOOL_CALL = "tool_call"              # 工具调用请求
    RESOURCE_ACCESS = "resource_access"  # 资源访问请求
    CAPABILITY_QUERY = "capability_query"  # 能力查询请求
    
    # 响应类型
    TOOL_RESULT = "tool_result"          # 工具调用结果
    RESOURCE_DATA = "resource_data"      # 资源数据
    CAPABILITY_INFO = "capability_info"  # 能力信息
    
    # 错误类型
    ERROR = "error"                      # 错误消息
    
    # 控制类型
    PING = "ping"                        # 心跳检测
    PONG = "pong"                        # 心跳响应

9.3.1.2 消息格式

所有 MCP 消息都遵循统一的格式：

@dataclass
class MCPMessage:
    message_id: str                      # 消息唯一标识符
    message_type: MCPMessageType         # 消息类型
    timestamp: datetime                  # 时间戳
    metadata: Dict[str, Any]             # 扩展元数据

请求消息包含工具名称和参数：

@dataclass(frozen=True)
class MCPRequest(MCPMessage):
    tool_name: str = ""                  # 工具名称
    parameters: Dict[str, Any] = field(default_factory=dict)  # 工具参数
    timeout: Optional[int] = None        # 超时时间（秒）

响应消息包含执行结果和状态：

@dataclass(frozen=True)
class MCPResponse(MCPMessage):
    request_id: str = ""                 # 对应的请求 ID
    result: Any = None                   # 工具执行结果
    status: str = "success"              # 执行状态
    execution_time: Optional[float] = None  # 执行时间（秒）

9.3.2 MCP 服务器

MCP 服务器负责接收智能体的工具调用请求并返回结果：

class MCPServer:
    """
    MCP 服务器
    
    用于接收智能体的工具调用请求并返回结果。
    支持工具注册、请求处理和响应发送。

    def __init__(self, name: str = "MCP Server"):
        self.name = name
        self._tools: Dict[str, Callable] = {}
        self._active_requests: Dict[str, Any] = {}
        self._stats = {
            "total_requests": 0,
            "successful_requests": 0,
            "failed_requests": 0

    def register_tool(

        """注册工具"""
        self._tools[name] = {
            "handler": handler,
            "description": description,
            "registered_at": datetime.now(timezone.utc)
        }
    
    def handle_request(self, request: MCPRequest) -> MCPResponse:
        """处理工具调用请求"""

        pass

9.3.3 MCP 客户端

MCP 客户端用于智能体向工具服务器发送请求并接收响应：

class MCPClient:
    """
    MCP 客户端
    
    用于智能体向工具服务器发送请求并接收响应。
    支持同步和异步调用，内置超时控制和错误处理。
    """
    
    def __init__(
        self,
        server_url: Optional[str] = None,
        timeout: int = 30,
        retry_count: int = 3
    ):
        self.server_url = server_url
        self.timeout = timeout
        self.retry_count = retry_count
    
    def call_tool(
        self,
        tool_name: str,
        parameters: Dict[str, Any],
        timeout: Optional[int] = None
    ) -> MCPResponse:
        """同步调用工具"""
        request = create_tool_call(
            tool_name=tool_name,
            parameters=parameters,
            timeout=timeout or self.timeout
        )
        return self._simulate_call(request)

from HelloAgents.protocols.mcp import (

9.4 A2A：智能体间的点对点协作

A2A（Agent-to-Agent Protocol）是一种用于智能体间点对点通信的协议。它支持直接消息传递、请求-响应模式和广播通信，使得智能体可以轻松地与其他智能体进行协作。

9.4.1 A2A 的核心概念

9.4.1.1 消息类型

A2A 定义了多种消息类型，支持不同的协作场景：

class A2AMessageType(str, Enum):
    # 直接消息
    DIRECT_MESSAGE = "direct_message"      # 直接消息
    BROADCAST = "broadcast"                # 广播消息
    
    # 请求-响应
    REQUEST = "request"                    # 请求消息
    RESPONSE = "response"                  # 响应消息
    
    # 协作消息
    TASK_DELEGATION = "task_delegation"    # 任务委托
    TASK_RESULT = "task_result"            # 任务结果
    STATUS_UPDATE = "status_update"        # 状态更新
    
    # 控制消息
    HEARTBEAT = "heartbeat"                # 心跳
    ACK = "ack"                            # 确认
    NACK = "nack"                          # 拒绝确认

9.4.1.2 消息优先级

A2A 支持消息优先级，确保重要消息能够优先处理：

class A2APriority(str, Enum):
    LOW = "low"
    NORMAL = "normal"
    HIGH = "high"
    URGENT = "urgent"

9.4.2 A2A 对等节点

A2A 对等节点表示网络中的一个智能体节点：

class A2APeer:
    """
    A2A 对等节点
    
    表示网络中的一个智能体节点，支持与其他节点进行通信。
    """
    
    def __init__(
        self,
        peer_id: str,
        name: str,
        capabilities: Optional[List[str]] = None
    ):
        self.peer_id = peer_id
        self.name = name
        self.capabilities = capabilities or []
        self._message_handlers: Dict[A2AMessageType, list] = {}
        self._peers: Dict[str, "A2APeer"] = {}
        self._stats = {
            "messages_sent": 0,
            "messages_received": 0,
            "messages_failed": 0
        }

9.4.3 使用示例

from HelloAgents.protocols.a2a import (
    A2APeer,
    A2AMessageType,
    create_direct_message,
    create_request,
)

# 创建两个对等节点
agent1 = A2APeer(
    peer_id="agent-001",
    name="研究助手",
    capabilities=["research", "analysis"]
)

agent2 = A2APeer(
    peer_id="agent-002",
    name="写作助手",
    capabilities=["writing", "editing"]
)

# 添加对等关系
agent1.add_peer(agent2)
agent2.add_peer(agent1)

# 注册消息处理器
def handle_message(message):
    print(f"{agent2.name} 收到消息: {message.content}")

agent2.register_handler(A2AMessageType.DIRECT_MESSAGE, handle_message)

# 发送直接消息
agent1.send_message(
    receiver_id="agent-002",
    content="你好，请帮我整理研究资料。"
)

# 发送请求
def handle_request(request):
    if request.action == "get_capabilities":
        return {"capabilities": agent2.capabilities}
    return None

agent2.register_handler(A2AMessageType.REQUEST, handle_request)

response = agent1.send_request(
    receiver_id="agent-002",
    action="get_capabilities",
    parameters={}
)
print(f"响应: {response.result}")

9.5 ANP：大规模智能体网络

ANP（Agent Network Protocol）是一种用于构建大规模智能体网络的协议。它支持网络拓扑管理、节点发现和路由，使得我们可以轻松地构建和管理包含数百甚至数千个智能体的网络。

9.5.1 ANP 的核心概念

9.5.1.1 网络拓扑

ANP 支持多种网络拓扑，适应不同的应用场景：

class NetworkTopology(str, Enum):
    STAR = "star"                    # 星型拓扑
    MESH = "mesh"                    # 网状拓扑
    RING = "ring"                    # 环型拓扑
    TREE = "tree"                    # 树型拓扑
    HIERARCHICAL = "hierarchical"    # 层次型拓扑

9.5.1.2 节点状态

ANP 跟踪节点的状态，确保网络的可靠性和性能：

class NodeStatus(str, Enum):
    ONLINE = "online"
    OFFLINE = "offline"
    BUSY = "busy"
    ERROR = "error"

9.5.2 ANP 网络节点

ANP 网络节点表示网络中的一个智能体节点：

class ANPNode:
    """
    ANP 网络节点
    
    表示网络中的一个智能体节点。
    """
    
    def __init__(
        self,
        node_id: str,
        name: str,
        capabilities: Optional[List[str]] = None
    ):
        self.node_id = node_id
        self.name = name
        self.capabilities = capabilities or []
        self.status = NodeStatus.ONLINE
        self.metadata: Dict[str, Any] = {}
        self.joined_at = datetime.now(timezone.utc)
        self.last_seen = datetime.now(timezone.utc)

9.5.3 ANP 网络

ANP 网络管理智能体网络的拓扑、节点和路由：

class ANPNetwork:
    """
    ANP 网络
    
    管理智能体网络的拓扑、节点和路由。
    """
    
    def __init__(
        self,
        network_id: str,
        name: str,
        topology: NetworkTopology = NetworkTopology.MESH
    ):
        self.network_id = network_id
        self.name = name
        self.topology = topology
        self._nodes: Dict[str, ANPNode] = {}
        self._edges: Dict[str, Set[str]] = {}
        self._routes: Dict[str, List[str]] = {}
        self._event_handlers: Dict[str, List[Callable]] = {}
        self.created_at = datetime.now(timezone.utc)
    
    def add_node(self, node: ANPNode) -> None:
        """添加节点到网络"""
        self._nodes[node.node_id] = node
        self._edges[node.node_id] = set()
        self._emit_event("node_joined", node)
    
    def find_path(self, from_node: str, to_node: str) -> Optional[List[str]]:
        """查找两个节点之间的路径（BFS）"""
        pass

        """发现节点"""
        pass

9.5.4 使用示例

from HelloAgents.protocols.anp import (
    ANPNode,
    ANPNetwork,
    NetworkTopology,
)

# 创建网络
network = ANPNetwork(
    network_id="network-001",
    name="智能协作网络",
    topology=NetworkTopology.MESH
)

# 创建网络节点
nodes = []
node_configs = [
    ("node-001", "数据处理节点", ["processing", "analysis"]),
    ("node-002", "知识库节点", ["storage", "retrieval"]),
    ("node-003", "推理节点", ["reasoning", "planning"]),
    ("node-004", "交互节点", ["communication", "ui"]),
]

for node_id, name, capabilities in node_configs:
    node = ANPNode(node_id=node_id, name=name, capabilities=capabilities)
    network.add_node(node)
    nodes.append(node)

# 建立网络连接
network.add_edge("node-001", "node-002")
network.add_edge("node-001", "node-003")
network.add_edge("node-002", "node-003")
network.add_edge("node-002", "node-004")
network.add_edge("node-003", "node-004")

# 查找路径
path = network.find_path("node-001", "node-004")
print(f"从 node-001 到 node-004 的路径: {' -> '.join(path)}")

# 发现节点
processing_nodes = network.discover_nodes(capability="processing")
print(f"具有 'processing' 能力的节点:")
for node in processing_nodes:
    print(f"  - {node.name} ({node.node_id})")

9.7 最佳实践

9.7.1 1. 选择合适的协议

根据应用场景选择合适的通信协议：

  • 工具调用：使用 MCP 协议，标准化工具接口
  • 智能体协作：使用 A2A 协议，支持点对点通信
  • 大规模网络：使用 ANP 协议，管理网络拓扑和路由

9.7.2 2. 错误处理和重试

def safe_call_tool(client, tool_name, parameters, max_retries=3):
    """安全地调用工具"""
    for i in range(max_retries):
        try:
            result = client.call_tool(tool_name, parameters)
            if result.status == "success":
                return result
        except Exception as e:
            if i == max_retries - 1:
                raise
            time.sleep(2 ** i)  # 指数退避
    return None
