6  Memory and Retrieval

Note上一章回顾

第 6 章我们构建了 HelloAgents 轻量框架，将 LLM 调用、消息管理、配置和 Agent 生命周期抽象为可复用组件。但这个框架有一个明显的缺口：Agent 的记忆仅限于当前对话（通过 _history 列表），一旦对话结束或超出长度限制，之前的交互信息就永久丢失了。本章将为 Agent 装上真正的”记忆系统”。

6.1 记忆与检索系统：让智能体拥有持续学习能力

在现代人工智能应用中，基于大语言模型（LLM）的智能体虽然表现出强大的理解和生成能力，但它们面临着两个根本性的局限：对话状态的遗忘和内置知识的局限性。如果智能体无法记住之前的交互内容，也无法从历史经验中学习，那么在连续对话或复杂任务中，其表现将受到极大限制。

本章将深入探讨两个核心能力：记忆系统（Memory System）和检索增强生成（Retrieval-Augmented Generation，RAG）。我们将从认知科学的角度理解记忆的原理，学习如何构建多层次的记忆系统，并掌握RAG技术的基础原理与高级应用策略。最重要的是，我们将基于 HelloAgents 框架 展示这些概念的实际实现。

6.2 认知科学启示：从人类记忆到智能体记忆

在构建智能体的记忆系统之前，让我们先从认知科学的角度理解人类是如何处理和存储信息的。人类记忆是一个多层级的认知系统，它不仅能存储信息，还能根据重要性、时间和上下文对信息进行分类和整理。

6.2.1 人类记忆系统的层次结构

根据认知心理学的研究，人类记忆可以分为以下几个层次：

感觉记忆（Sensory Memory）：持续时间极短（0.5-3秒），容量巨大，负责暂时保存感官接收到的所有信息。这是记忆系统的第一个阶段，信息在这里被短暂保留，只有被注意到的信息才会进入下一阶段。

工作记忆（Working Memory）：持续时间短（15-30秒），容量有限（7±2个项目），负责当前任务的信息处理。工作记忆就像计算机的内存，用于处理当前正在进行的认知活动，如理解句子、解决问题等。

长期记忆（Long-term Memory）：持续时间长（可达终生），容量几乎无限，进一步分为：

  • 程序性记忆：技能和习惯（如骑自行车、打字），通常难以用语言表达，但可以通过练习获得
  • 陈述性记忆：可以用语言表达的知识，又分为：
    • 语义记忆：一般知识和概念（如”巴黎是法国首都”、“勾股定理”），不依赖于特定的时间和地点
    • 情景记忆：个人经历和事件（如”昨天的会议内容”、“去年夏天的旅行”），与特定的时间和空间相关联

6.2.2 为何智能体需要记忆与RAG

借鉴人类记忆系统的设计，我们可以理解为什么智能体也需要类似的记忆能力。对于基于LLM的智能体而言，通常面临两个根本性局限：对话状态的遗忘和内置知识的局限。

6.2.2.1 局限一：无状态导致的对话遗忘

当前的大语言模型虽然强大，但设计上是无状态的。这意味着，每一次用户请求（或API调用）都是一次独立的、无关联的计算。模型本身不会自动”记住”上一次对话的内容。这带来了几个问题：

  • 上下文丢失：在长对话中，早期的重要信息可能会因为上下文窗口限制而丢失
  • 个性化缺失：Agent无法记住用户的偏好、习惯或特定需求
  • 学习能力受限：无法从过往的成功或失败经验中学习改进
  • 一致性问题：在多轮对话中可能出现前后矛盾的回答

让我们通过一个具体例子来理解这个问题：

# 传统无状态LLM的使用方式
response1 = llm.generate("我叫张三，正在学习Python，目前掌握了基础语法")
print(response1)  # "很好！Python基础语法是编程的重要基础..."

response2 = llm.generate("你还记得我的学习进度吗？")
print(response2)  # "抱歉，我不知道您的学习进度..."

要解决这个问题，智能体系统需要引入记忆机制来保存和检索历史对话信息。

6.2.2.2 局限二：模型内置知识的局限性

除了遗忘对话历史，LLM的另一个核心局限在于其知识是静态的、有限的。这些知识完全来自于它的训练数据，并因此带来一系列问题：

  • 知识时效性：大模型的训练数据有时间截止点，无法获取最新信息
  • 专业领域知识：通用模型在特定领域的深度知识可能不足
  • 事实准确性：通过检索验证，减少模型的幻觉问题
  • 可解释性：提供信息来源，增强回答的可信度

为了克服这一局限，RAG技术应运而生。它的核心思想是在模型生成回答之前，先从一个外部知识库（如文档、数据库、API）中检索出最相关的信息，并将这些信息作为上下文一同提供给模型。

6.3 HelloAgents 框架中的记忆系统实现

基于认知科学的启发，我们在 HelloAgents 框架中实现了一套完整的记忆系统。该系统模仿人类大脑处理不同类型信息的方式，将记忆划分为多个专门的模块，并建立了一套智能化的管理机制。

6.3.1 记忆系统的四层架构

HelloAgents 的记忆系统包含以下四个层次：

记忆系统架构
├── 基础设施层 (Infrastructure Layer)
│   ├── MemoryManager - 记忆管理器（统一调度和协调）
│   ├── MemoryItem - 记忆数据结构（标准化记忆项）
│   ├── MemoryType - 记忆类型枚举
│   └── BaseMemory - 记忆基类（通用接口定义）
├── 记忆类型层 (Memory Types Layer)
│   ├── WorkingMemory - 工作记忆（临时信息，TTL管理）
│   ├── EpisodicMemory - 情景记忆（具体事件，时间序列）
│   ├── SemanticMemory - 语义记忆（抽象知识，图谱关系）
│   └── PerceptualMemory - 感知记忆（多模态数据）
└── 存储后端层 (Storage Backend Layer)
    └── 混合存储架构（内存 + 可扩展持久化）

6.3.4 四种记忆类型的实现

6.3.4.1 1. WorkingMemory - 工作记忆

工作记忆是记忆系统中最活跃的部分，它负责存储当前对话会话中的临时信息。

特点： - 容量有限（默认50条）+ TTL自动清理 - 纯内存存储，访问速度极快 - 混合检索：TF-IDF向量化 + 关键词匹配

关键实现：

class WorkingMemory(BaseMemory):
    def __init__(self, max_capacity: int = 50, ttl_seconds: int = 1800):
        super().__init__(name="working_memory", max_capacity=max_capacity)
        self.ttl_seconds = ttl_seconds  # 记忆生存时间

    def search(self, query: str, limit: int = 10, min_importance: float = 0.0, **kwargs):
        # 混合检索：TF-IDF + 关键词匹配
        try:
            scores = self._tfidf_search(query, candidates)
        except Exception:
            scores = self._keyword_search(query, candidates)

        # 结合时间衰减和重要性权重
        final_score = (similarity * time_decay) * (0.8 + importance * 0.4)

使用示例：

from HelloAgents.memory import MemoryManager, MemoryType

# 创建记忆管理器
memory_manager = MemoryManager()

# 添加工作记忆
memory_manager.add(
    content="用户刚才问了关于Python函数的问题",
    memory_type=MemoryType.WORKING,
    importance=0.6,
    session_id="session_1"
)

# 搜索记忆
results = memory_manager.search(query="Python", limit=5)

6.3.4.2 2. EpisodicMemory - 情景记忆

情景记忆负责存储具体的事件和经历，它的设计重点在于保持事件的完整性和时间序列关系。

特点： - 支持时间序列和会话级检索 - 结构化过滤 + 语义向量检索 - 评分公式：(向量相似度 × 0.8 + 时间近因性 × 0.2) × (0.8 + 重要性 × 0.4)

使用示例：

# 添加情景记忆
memory_manager.add(
    content="2024年3月15日，用户张三完成了第一个Python项目",
    memory_type=MemoryType.EPISODIC,
    importance=0.8,
    session_id="session_1",
    event_type="milestone",
    location="在线学习平台"
)

# 按会话检索
from HelloAgents.memory import EpisodicMemory
episodic_memory = memory_manager.episodic
session_memories = episodic_memory.get_by_session("session_1")

6.3.4.3 3. SemanticMemory - 语义记忆

语义记忆是记忆系统中最复杂的部分，它负责存储抽象的概念、规则和知识。

特点： - 自动提取实体和关系，构建知识图谱 - 混合检索策略：向量+图+语义推理 - 评分公式：(向量相似度 × 0.7 + 图相似度 × 0.3) × (0.8 + 重要性 × 0.4)

使用示例：

# 添加语义记忆
memory_manager.add(
    content="Python是一种解释型、面向对象的编程语言",
    memory_type=MemoryType.SEMANTIC,
    importance=0.9,
    knowledge_type="factual"
)

# 获取知识图谱中的实体
entities = memory_manager.semantic.get_entities()

6.3.4.4 4. PerceptualMemory - 感知记忆

感知记忆支持文本、图像、音频等多种模态的数据存储和检索。

特点： - 支持多模态数据（文本、图像、音频等） - 跨模态相似性搜索 - 模态分离存储策略

使用示例：

# 添加感知记忆
memory_manager.add(
    content="用户上传了一张Python代码截图",
    memory_type=MemoryType.PERCEPTUAL,
    importance=0.7,
    modality="image",
    file_path="./uploads/code.png",
    tags=["Python", "代码"]
)

# 按模态检索
image_memories = memory_manager.perceptual.get_by_modality("image")

6.4 HelloAgents 框架中的 RAG 系统实现

RAG（Retrieval-Augmented Generation，检索增强生成）是一种结合了信息检索和文本生成的技术。HelloAgents 框架实现了一套完整的 RAG 系统，包括文档处理、向量存储、检索和提示词生成等功能。

6.4.1 RAG 系统架构

RAG 系统架构
├── 基础层 (Base Layer)
│   ├── Document - 文档数据结构
│   └── RAGConfig - 配置管理
├── 处理层 (Processing Layer)
│   └── DocumentProcessor - 文档处理器
├── 存储层 (Storage Layer)
│   └── VectorStore - 向量存储
├── 检索层 (Retrieval Layer)
│   └── Retriever - 检索器
└── 系统层 (System Layer)
    └── RAGSystem - RAG 系统主类

        return [Document(...)]

6.5 记忆系统与 RAG 的协同应用

记忆系统和 RAG 系统虽然各自独立，但它们可以协同工作，为智能体提供更强大的能力。通过将两个系统有机结合，可以构建更加智能的应用。

6.5.1 协同工作模式

6.5.1.1 1. 知识积累模式

用户通过 RAG 系统查询外部知识库，将重要的查询结果自动存储到记忆系统中。

# 使用 RAG 检索知识
retrieval_result, prompt = rag.query(query="Python 的特点是什么？")

# 调用 LLM 生成答案
response = llm.invoke([Message(role="user", content=prompt)])

# 将重要的答案存储到语义记忆
memory_manager.add(
    content=f"Python 的特点：{response}",
    memory_type=MemoryType.SEMANTIC,
    importance=0.8
)

6.5.1.2 2. 个性化推荐模式

记忆系统记录用户的历史查询、偏好和行为模式，RAG 系统根据这些个性化信息进行更精准的知识检索。

# 从记忆中获取用户偏好
user_preferences = memory_manager.search(
    query="用户感兴趣的编程主题",
    memory_types=[MemoryType.SEMANTIC],
    limit=5
)

# 构建个性化查询
personalized_query = f"{query} （用户偏好：{', '.join([m.content for m in user_preferences])}）"

# 使用个性化查询检索
retrieval_result, prompt = rag.query(personalized_query)

6.5.1.3 3. 学习反馈模式

智能体通过记忆系统记录用户对答案的反馈（如点赞、纠正、追问），不断优化 RAG 系统的检索策略。

# 记录用户反馈
memory_manager.add(
    content=f"用户对答案的反馈：{user_feedback}",
    memory_type=MemoryType.EPISODIC,
    importance=0.7
)

# 基于反馈优化检索（简化版）
if "不准确" in user_feedback:
    # 降低相似度阈值，检索更多文档
    rag.config.similarity_threshold *= 0.9

6.5.2 实际应用案例：智能学习助手

结合记忆系统和 RAG 系统，我们可以构建一个智能学习助手：

from HelloAgents.core.agent import Agent
from HelloAgents.memory import MemoryManager, MemoryType
from HelloAgents.rag import RAGSystem, DocumentProcessor

class SmartLearningAgent(Agent):
    """
    智能学习助手

    功能：
    - 记住学习进度和偏好
    - 从知识库中检索相关信息
    - 提供个性化的学习建议
    """

    def __init__(self, name: str, llm, memory_manager: MemoryManager, rag_system: RAGSystem):
        super().__init__(name=name, llm=llm)
        self.memory_manager = memory_manager
        self.rag_system = rag_system

    def _execute(self, *, messages, **kwargs):
        # 1. 提取用户问题
        user_question = messages[-1].content

        # 2. 从记忆中检索相关上下文
        memory_context = self._get_memory_context(user_question)

        # 3. 从 RAG 系统检索知识
        retrieval_result, rag_prompt = self.rag_system.query(user_question, top_k=3)

        # 4. 构建增强的提示词
        enhanced_prompt = f"""
        你是一个智能学习助手。
        
        用户学习历史：
        {memory_context}
        
        相关知识：
        {rag_prompt}
        
        请基于以上信息回答用户问题，并提供个性化的学习建议。
        """

        # 5. 调用 LLM
        response = self.llm.invoke([Message(role="user", content=enhanced_prompt)])

        # 6. 记录对话
        self.memory_manager.add(
            content=user_question,
            memory_type=MemoryType.WORKING,
            importance=0.6
        )
        self.memory_manager.add(
            content=response,
            memory_type=MemoryType.WORKING,
            importance=0.6
        )

        return response

    def _get_memory_context(self, query: str) -> str:
        """获取记忆上下文"""
        memories = self.memory_manager.search(
            query=query,
            limit=5,
            min_importance=0.5
        )
        if not memories:
            return "（暂无学习历史）"
        
        context_parts = [f"[{mem.memory_type.value}] {mem.content}" for mem in memories]
        return "\n".join(context_parts)

    def learn_preference(self, preference: str):
        """学习用户偏好"""
        self.memory_manager.add(
            content=f"用户偏好：{preference}",
            memory_type=MemoryType.SEMANTIC,
            importance=0.8
        )

    def add_knowledge(self, content: str):
        """添加知识到知识库"""
        processor = DocumentProcessor()
        doc = processor.load_from_text(content, doc_id=f"doc_{len(self.rag_system.vector_store.documents)}")
        self.rag_system.add_document(doc)
