三条核心原则

如果你只能从本书带走三个东西，请记住这三条：

1. Agent ≠ ChatBot

Agent 与 ChatBot 的分水岭在于工具调用。ChatBot 只会”说”；Agent 会主动”做”——查询天气、搜索信息、执行代码。工具系统是 Agent 的第一能力扩展点。

2. Prompt 在 Agent 中是协议，不是提示词

Agent 的 System Prompt 本质上是一份输出格式协议——它定义了 Thought/Action 标签、工具调用语法和终止条件。LLM 的输出必须能被代码精确解析。设计 Prompt 的本质是设计通信协议。

3. 从简单开始，逐步叠加

不要一上来就构建 5 个 Agent 的复杂系统。从最简单的对话 Agent 开始，逐步叠加能力：+ 工具 → + 推理 → + 记忆 → + 多 Agent。每一步都能独立运行和测试。

继续前进的方向

Agent 技术仍在快速演进。以下方向值得持续关注：

  • Agentic AI 产品化：如何将 Agent 从 Demo 变成生产级应用？关注可观测性、安全护栏、成本控制。
  • 多模态 Agent：Agent 不仅能处理文本，还能理解图像、语音和视频。
  • Agent 操作系统：当 Agent 成为新一代应用范式，如何管理 Agent 的生命周期、权限和资源？
  • Code Agent：以代码生成和执行作为核心能力的 Agent，正在改变软件开发的范式。
  • Agent 安全与对齐：随着 Agent 自主性增强，如何确保其行为安全、可控、符合人类意图？

致读者

学习 Agent 的最好方式不是读完一本书，而是亲手构建一个。本书的每一章都包含了可运行的代码和练习——如果你还没有动手实现过，现在就是最好的时机。

从一行 agent.run("Hello") 开始，走向构建能自主完成复杂任务的智能系统。祝你在这条路上走得愉快。

# 你从这儿开始
agent = SimpleAgent(name="我的第一个Agent", llm=llm)
print(agent.run("你好，世界！"))
