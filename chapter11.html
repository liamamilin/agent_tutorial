11  Intelligent Agent Performance Evaluation

11.1 智能体性能评估

在前面的章节中，我们构建了 HelloAgents 框架的核心功能，实现了多种智能体范式、工具系统、记忆机制和强化学习训练等。在构建智能体系统时，我们还需要解决一个核心问题：如何客观地评估智能体的性能？

具体来说，我们需要回答以下问题：

  • 智能体是否具备预期的能力？
  • 在不同任务上的表现如何？
  • 与其他智能体相比处于什么水平？

本章将介绍 HelloAgents 框架的智能体性能评估系统，帮助你建立完善的评估体系，量化智能体的能力，并持续改进智能体的性能。

11.2 评估基础

11.2.1 为什么需要评估？

智能体评估是智能体开发过程中不可或缺的一环，它帮助我们：

  1. 验证能力：确认智能体是否具备预期的功能和性能
  2. 发现问题：发现智能体的弱点和改进空间
  3. 优化决策：基于数据做出优化决策，而不是凭直觉
  4. 对比分析：比较不同智能体或不同配置的性能差异
  5. 持续改进：跟踪智能体的性能变化，确保改进的有效性

11.2.2 评估的核心要素

智能体评估涉及以下几个核心要素：

  • 评估指标（Metrics）：用于衡量智能体性能的标准
  • 评估任务（Tasks）：智能体需要完成的具体任务
  • 评估数据集（Dataset）：一组相关的评估任务
  • 评估器（Evaluator）：执行评估过程的组件
  • 评估报告（Report）：汇总和展示评估结果

11.3 评估指标

评估指标是衡量智能体性能的标准。HelloAgents 框架提供了多种内置指标，并支持自定义指标。

11.3.1 准确率指标（AccuracyMetric）

准确率指标用于衡量智能体输出的正确性，支持两种匹配模式：

from HelloAgents.evaluation import AccuracyMetric

# 精确匹配
accuracy_exact = AccuracyMetric(name="accuracy", match_type="exact")

# 包含匹配
accuracy_contains = AccuracyMetric(name="accuracy", match_type="contains")

精确匹配：要求输出与期望完全一致

result = accuracy_exact.compute(
    input_text="What is 2 + 2?",
    output_text="4",
    expected_output="4"
)
# result.value = 1.0 (正确)

包含匹配：要求输出包含期望内容

result = accuracy_contains.compute(
    input_text="What is the capital of France?",
    output_text="The capital of France is Paris.",
    expected_output="Paris"
)
# result.value = 1.0 (正确)

11.3.2 响应时间指标（ResponseTimeMetric）

响应时间指标用于衡量智能体的响应速度：

from HelloAgents.evaluation import ResponseTimeMetric

response_time_metric = ResponseTimeMetric(name="response_time")

result = response_time_metric.compute(
    input_text="Test input",
    output_text="Test output",
    metadata={"response_time": 1.5}  # 响应时间（秒）
)
# result.value = 1.5

11.3.3 Token 使用指标（TokenUsageMetric）

Token 使用指标用于衡量智能体的资源消耗：

from HelloAgents.evaluation import TokenUsageMetric

token_metric = TokenUsageMetric(name="token_usage")

result = token_metric.compute(
    input_text="This is a test input.",
    output_text="This is a test output."
)
# result.details["input_tokens"] = 5
# result.details["output_tokens"] = 5
# result.details["total_tokens"] = 10

11.3.4 自定义指标（CustomMetric）

自定义指标允许你根据特定需求创建评估标准：

from HelloAgents.evaluation import CustomMetric

def output_length_metric(input_text, output_text, expected_output, metadata):
    """自定义指标：输出长度"""
    return {
        "value": len(output_text),
        "details": {"output_length": len(output_text)}
    }

custom_metric = CustomMetric(
    metric_fn=output_length_metric,
    name="output_length"
)

result = custom_metric.compute(
    input_text="Test",
    output_text="This is a longer output."
)
# result.value = 24.0

11.4 评估任务

评估任务定义了智能体需要完成的具体工作。

11.4.1 创建评估任务

from HelloAgents.evaluation import EvaluationTask

task = EvaluationTask(
    task_id="task_001",
    input_text="What is 2 + 2?",
    expected_output="4",
    metadata={"category": "math", "difficulty": "easy"}
)

11.4.2 任务数据集

任务数据集用于管理多个评估任务：

from HelloAgents.evaluation import TaskDataset

# 创建数据集
dataset = TaskDataset(name="Math Problems")

# 添加任务
dataset.add_task(EvaluationTask(
    task_id="task_001",
    input_text="What is 2 + 2?",
    expected_output="4"
))

dataset.add_task(EvaluationTask(
    task_id="task_002",
    input_text="What is 5 * 6?",
    expected_output="30"
))

# 从字典添加任务
dataset.add_task_from_dict({
    "task_id": "task_003",
    "input_text": "What is 10 / 2?",
    "expected_output": "5"
})

# 获取任务
task = dataset.get_task("task_001")
all_tasks = dataset.get_all_tasks()

print(f"数据集名称: {dataset.name}")
print(f"任务数量: {len(dataset)}")

11.5 评估器

评估器负责执行评估过程，计算各种指标。

11.5.1 单个智能体评估

from HelloAgents.evaluation import Evaluator, AccuracyMetric, ResponseTimeMetric

# 创建评估器
evaluator = Evaluator(
    name="MathEvaluator",
    metrics=[
        AccuracyMetric(name="accuracy"),
        ResponseTimeMetric(name="response_time")
    ]
)

# 评估单个任务
result = evaluator.evaluate_agent(agent, task)

# 评估整个数据集
results = evaluator.evaluate_dataset(agent, dataset)

11.5.2 批量评估

批量评估器支持同时评估多个智能体：

from HelloAgents.evaluation import BatchEvaluator

# 创建批量评估器
batch_evaluator = BatchEvaluator(
    name="BatchEvaluator",
    metrics=[
        AccuracyMetric(name="accuracy"),
        ResponseTimeMetric(name="response_time")
    ]
)

# 评估多个智能体
agents = {
    "Agent1": agent1,
    "Agent2": agent2,
    "Agent3": agent3
}

agent_results = batch_evaluator.evaluate_multiple_agents(agents, dataset)

11.5.3 智能体比较

比较多个智能体的性能：

# 比较智能体
comparison = batch_evaluator.compare_agents(
    agent_results,
    metric_name="accuracy"
)

for agent_name, metric_value in comparison.items():
    print(f"{agent_name}: {metric_value:.2f}")

# 获取最佳智能体
best_agent = batch_evaluator.get_best_agent(
    agent_results,
    metric_name="accuracy"
)
print(f"最佳智能体: {best_agent}")

11.6 评估报告

评估报告用于汇总和展示评估结果。

11.6.1 创建报告

from HelloAgents.evaluation import EvaluationReport

# 创建报告
report = EvaluationReport(
    evaluator_name="MathEvaluator",
    agent_name="MathAgent"
)

# 添加任务结果
report.add_task_results(results)

# 计算指标摘要
report.compute_metric_summaries()

# 打印摘要
report.print_summary()

11.6.2 保存报告

评估报告支持多种格式：

# 保存为 JSON
report.save_to_json("outputs/evaluation_report.json")

# 保存为 Markdown
report.save_to_markdown("outputs/evaluation_report.md")

11.6.3 报告内容

评估报告包含以下信息：

  • 概览：任务总数、成功/失败任务、成功率
  • 指标摘要：各指标的平均值、标准差、最小值、最大值
  • 失败任务：列出所有失败的任务及其详细信息

11.7 实战：评估数学问题解答智能体

让我们通过一个完整的例子来展示如何使用评估系统。

11.7.1 定义智能体

class MathSolverAgent:
    """数学问题解答智能体"""
    
    def __init__(self, name: str):
        self.name = name
    
    def run(self, input_text: str) -> str:
        """解答数学问题"""
        # 简单实现：解析并计算
        import re
        
        # 提取数字和运算符
        pattern = r"(\d+)\s*([\+\-\*\/])\s*(\d+)"
        match = re.search(pattern, input_text)
        
        if match:
            a, op, b = match.groups()
            a, b = int(a), int(b)
            
            if op == "+":
                return str(a + b)
            elif op == "-":
                return str(a - b)
            elif op == "*":
                return str(a * b)
            elif op == "/":
                return str(a / b)
        
        return "Unknown problem"

11.7.2 创建评估任务

dataset = TaskDataset(name="Math Problems")

tasks = [
    ("task_001", "What is 2 + 2?", "4"),
    ("task_002", "What is 5 * 6?", "30"),
    ("task_003", "What is 10 / 2?", "5"),
    ("task_004", "What is 3 + 7?", "10"),
    ("task_005", "What is 8 - 3?", "5"),
]

for task_id, input_text, expected_output in tasks:
    dataset.add_task(EvaluationTask(
        task_id=task_id,
        input_text=input_text,
        expected_output=expected_output
    ))

11.7.3 执行评估

# 创建智能体
agent = MathSolverAgent(name="MathSolver")

# 创建评估器
evaluator = Evaluator(
    name="MathEvaluator",
    metrics=[
        AccuracyMetric(name="accuracy"),
        ResponseTimeMetric(name="response_time"),
        TokenUsageMetric(name="token_usage")
    ]
)

# 评估
results = evaluator.evaluate_dataset(agent, dataset)

# 创建报告
report = EvaluationReport(
    evaluator_name="MathEvaluator",
    agent_name="MathSolver"
)
report.add_task_results(results)
report.compute_metric_summaries()

# 打印报告
report.print_summary()

# 保存报告
report.save_to_json("outputs/math_agent_report.json")
report.save_to_markdown("outputs/math_agent_report.md")

11.8 进阶：多智能体对比

让我们对比多个智能体的性能：

# 创建多个智能体
class SimpleMathAgent:
    """简单数学智能体"""
    def run(self, input_text: str) -> str:
        import re
        match = re.search(r"(\d+)\s*([\+\-\*\/])\s*(\d+)", input_text)
        if match:
            a, op, b = int(match.group(1)), match.group(2), int(match.group(3))
            if op == "+": return str(a + b)
            if op == "-": return str(a - b)
            if op == "*": return str(a * b)
            if op == "/": return str(a / b)
        return "Unknown"

class VerboseMathAgent:
    """详细数学智能体"""
    def run(self, input_text: str) -> str:
        import re
        match = re.search(r"(\d+)\s*([\+\-\*\/])\s*(\d+)", input_text)
        if match:
            a, op, b = int(match.group(1)), match.group(2), int(match.group(3))
            if op == "+": return f"The sum of {a} and {b} is {a + b}"
            if op == "-": return f"The difference of {a} and {b} is {a - b}"
            if op == "*": return f"The product of {a} and {b} is {a * b}"
            if op == "/": return f"The quotient of {a} and {b} is {a / b}"
        return "I cannot solve this problem"

# 批量评估
agents = {
    "SimpleMath": SimpleMathAgent(),
    "VerboseMath": VerboseMathAgent()
}

batch_evaluator = BatchEvaluator(
    name="BatchEvaluator",
    metrics=[
        AccuracyMetric(name="accuracy", match_type="contains"),
        ResponseTimeMetric(name="response_time")
    ]
)

agent_results = batch_evaluator.evaluate_multiple_agents(agents, dataset)

# 比较
comparison = batch_evaluator.compare_agents(agent_results, "accuracy")
print("\n智能体对比:")
for agent_name, metric_value in comparison.items():
    print(f"  {agent_name}: {metric_value:.2f}")

# 最佳智能体
best_agent = batch_evaluator.get_best_agent(agent_results, "accuracy")
print(f"\n最佳智能体: {best_agent}")

11.9 评估最佳实践

11.9.1 1. 选择合适的指标

根据任务类型选择合适的评估指标：

  • 事实性任务：使用准确率指标
  • 实时性任务：使用响应时间指标
  • 资源受限任务：使用 Token 使用指标
  • 创意性任务：使用自定义指标

11.9.2 2. 构建多样化的数据集

确保评估数据集具有代表性：

# 多样化数据集
dataset = TaskDataset(name="Comprehensive Dataset")

# 不同难度级别
dataset.add_task(EvaluationTask(
    task_id="easy_001",
    input_text="What is 2 + 2?",
    expected_output="4",
    metadata={"difficulty": "easy"}
))

dataset.add_task(EvaluationTask(
    task_id="medium_001",
    input_text="What is 15 * 7?",
    expected_output="105",
    metadata={"difficulty": "medium"}
))

dataset.add_task(EvaluationTask(
    task_id="hard_001",
    input_text="What is 123 * 456?",
    expected_output="56088",
    metadata={"difficulty": "hard"}
))

11.9.3 3. 定期评估

建立定期评估机制，跟踪性能变化：

def run_periodic_evaluation(agent, dataset, output_dir="outputs"):
    """定期评估"""
    evaluator = Evaluator(
        name="PeriodicEvaluator",
        metrics=[AccuracyMetric(), ResponseTimeMetric()]
    )
    
    results = evaluator.evaluate_dataset(agent, dataset)
    
    report = EvaluationReport(
        evaluator_name="PeriodicEvaluator",
        agent_name=agent.name
    )
    report.add_task_results(results)
    report.compute_metric_summaries()
    
    # 使用时间戳命名文件
    from datetime import datetime
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    
    report.save_to_json(f"{output_dir}/report_{timestamp}.json")
    
    return report

11.9.4 4. 分析失败案例

深入分析失败的任务，找出改进方向：

report.print_summary()

# 获取失败任务
failed_tasks = report.get_failed_tasks()

print(f"\n失败任务数: {len(failed_tasks)}")
for task in failed_tasks:
    print(f"\n任务 {task.task_id}:")
    print(f"  输入: {task.input_text}")
    print(f"  输出: {task.output_text}")
    print(f"  期望: {task.expected_output}")
    if task.error:
        print(f"  错误: {task.error}")
