工具系统简介

工具（Tool）是 Agent 与外部世界交互的接口。工具可以是 API 调用、数据库查询、代码执行、文件操作等。

一个良好定义的工具包含三个核心要素：名称（唯一标识符）、描述（告诉 LLM 何时使用）、执行逻辑（实际执行任务的函数）。

工具调用流程：用户提出请求 → LLM 分析并决定使用哪个工具 → Agent 解析工具调用 → 执行工具 → 结果回填给 LLM → LLM 基于结果生成最终回复。

OpenAI 提供了原生的 Function Calling 机制，让模型能够输出结构化的工具调用，而不是自由文本。这大大提高了工具调用的可靠性。

常见的工具包括：天气查询、搜索引擎、计算器、代码解释器、数据库查询等。工具系统是 Agent 与 ChatBot 的分水岭。
