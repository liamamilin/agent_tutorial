智能体（Agent）简介

智能体（Agent）是指能够通过传感器感知环境，并自主地借助执行器采取行动，以实现特定目标的实体。

智能体的四个核心要素：环境、传感器、执行器和目标。环境是智能体所处的外部世界，传感器用于获取环境信息，执行器用于对环境施加影响，目标是智能体需要达成的任务。

LLM 智能体是由大语言模型驱动的智能体，与传统基于规则的智能体不同，LLM 智能体可以理解自然语言指令，具备强大的推理和泛化能力。

典型的 LLM 智能体架构包括：感知模块、推理模块（LLM 核心）、工具调用模块、记忆模块。它们通过 "感知—决策—行动" 的循环持续运行。

常见的 Agent 推理范式包括 ReAct（推理与行动交替）、Plan-and-Solve（先规划再执行）和 Reflection（执行后自我反思）。
